# 计算专题 · 公式卡 + 解题步骤卡

> 依据：《03：26.10计算专题》全 100 页（公式与例题已逐页核对）+《01：26.10名师讲义》对应页。
> 讲义页码：进度 P121–126（三点估算/关键路径/资源）、成本 EVM P161–163、合同 P144、风险定量 P137–138。
> 计算专题页码：篇一进度 P2–P19；篇二成本 P20–P40；篇三综合 P41–P63；篇四其他 P64–P71；答案 P72–P100。

## 0. 通用五步（所有计算题都套）
1. **圈数据**：把题干的"计划/实际/完成百分比/概率/历时"抄成一张表，缺的量先补算。
2. **选公式**：先判断题目问的是"偏差/指数"还是"预测（ETC/EAC/VAC/TCPI）"。
3. **列式代入**：**先写公式再代数**（案例题按步骤给分，答案错也能拿步骤分）。
4. **判断结论**：`>0` 是好、`<0` 是坏；`>1` 是好、`<1` 是坏——一定要写出"超支/节约、超前/滞后"。
5. **答一句结论**：把数字翻译成管理语言（例："CPI=0.82，成本超支 18%"）。

# 篇一 进度计算（P2–P19）

## 1.1 四种活动依赖关系（P2）
| 类型 | 全称 | 含义 |
|---|---|---|
| **F-S** | 完成-开始 | 前序**结束**，后续才能**开始**（最常用） |
| **F-F** | 完成-完成 | 前序**结束**，后续才能**结束** |
| **S-S** | 开始-开始 | 前序**开始**，后续才能**开始** |
| **S-F** | 开始-完成 | 前序**开始**，后续才能**结束** |

**提前量与滞后量**（P3）：提前量＝紧后活动**可以提前**的时间量（图上标 **-2 周**）；滞后量＝紧后活动**需要推迟**的时间量（图上标 **+15 天**）。口诀：**提前为减，滞后为加**。

## 1.2 六个时间参数 + 两个浮动公式（P2–P3）
| 参数 | 含义 | 算法 |
|---|---|---|
| ES | 最早开始 | 顺推：`ES = max(紧前活动 EF)` |
| EF | 最早结束 | `EF = ES + 工期` |
| LS | 最迟开始 | 逆推：`LS = LF - 工期` |
| LF | 最迟结束 | 逆推：`LF = min(紧后活动 LS)` |
| **TF 总浮动** | 不影响**总工期**可耽误的时间 | `TF = LS - ES = LF - EF` |
| **FF 自由浮动** | 不影响**任何紧后活动最早开始**可耽误的时间 | `FF = min(紧后活动 ES) - 本活动 EF` |

**关键活动：TF = FF = 0**（讲义原话"温馨提示：关键活动的总时差、自由时差都为 0"）。

## 1.3 网络图口决（本书原话，P5）
> **顺推为上，必取大；逆推为下，必取小。**
> **自由浮动时间：后减前；总浮动时间：下减上。**
> **时间提前量为减，时间滞后量为加。**

- "上"＝图上第一排（最早时间 ES/EF），"下"＝第二排（最迟时间 LS/LF），所以"下减上"＝LS−ES 或 LF−EF。
- "后减前"＝紧后活动的 ES 减去本活动的 EF。

## 1.4 关键路径（P4–P5）
- **定义**：所有从开始到结束的路径中，**活动历时之和最大**的那条路径。
- **总工期**＝任一关键路径上的活动历时之和。
- 关键路径**可能有多条**；关键路径决定项目**最短工期**。
- 做题两种打法：
  1. **穷举路径法**（节点少时最快）：把所有路径长度都算出来，最长者即关键路径（例题：4 条路径 14/18/9/14 → 关键路径 B-E-H-J＝18 天）。
  2. **顺推+逆推法**（节点多时必用）：见下。

## 1.5 画图与标记五步（表格式题必考）
1. 读紧前关系表，**找出没有紧前工作的活动**，从"开始"节点引出。
2. 逐个活动画节点（单代号：方框=活动，箭头=逻辑关系）。
3. **顺推**：从左到右填 ES/EF，遇到多条汇入**取大**。
4. **逆推**：从右到左填 LS/LF，遇到多条分叉**取小**。
5. 算 TF、FF，**TF=0 的连线串起来就是关键路径**，同时得到总工期。

**示例结论**（P6 例题）：关键路径 ACDGH，总工期 48 天。

## 1.6 双代号网络图与虚活动（P4）
- 箭线图法（双代号）：**箭线=活动，节点=事件**；箭尾事件=紧前事件，箭头事件=紧后事件。
- **虚活动不消耗时间，也不消耗资源**，只用于表达逻辑关系（判断题常考原话）。

## 1.7 工期压缩（赶工）四步
1. 找出**关键路径**（只有压缩关键路径上的活动才能缩短总工期）。
2. 在关键活动里选**单位时间赶工成本最低**的。
3. 压缩时**不能超过该活动的"正常时间−最短时间"**上限。
4. **压完必须重算**：可能出现新的关键路径（原次关键路径追上来），关键路径可能变多。

## 1.8 资源平衡 vs 资源平滑（讲义 P123–P124）
| | 资源平衡 | 资源平滑 |
|---|---|---|
| 做法 | 按资源制约调整活动**开始/结束日期** | 只在**浮动时间**内调整活动 |
| 对关键路径 | **往往改变关键路径** | **不改变关键路径** |
| 对工期 | **通常延长工期** | **不延长完工日期** |
| 目的 | 资源需求与供给平衡 | 资源需求不超过预定限制 |

# 篇二 成本计算 · 挣值管理 EVM（P20–P40；讲义 P161–P163）

## 2.1 三个基础量（P20 表）
| 缩写 | 名称 | 一句话 | 公式 |
|---|---|---|---|
| **PV** | 计划值 | **应该干多少** | `PV = 计划工作量 × 计划单价` |
| **EV** | 挣值 | **干了多少**（按预算价折算） | `EV = 实际工作量 × 计划单价`；表格式题用 `EV = 完成百分比 × PV` |
| **AC** | 实际成本 | **花了多少** | 题目一般直接给 |

> 铁律：**EV 一律用"计划单价"算**；EV 与 PV 口径必须对应，**EV 不得大于该组件的 PV 总预算**；**AC 没有上限**（讲义 P163 注）。

## 2.2 四个偏差/指数（必背判读）
| 指标 | 公式 | 判读 |
|---|---|---|
| **CV 成本偏差** | `CV = EV - AC` | `>0` 成本节约；`<0` 成本超支 |
| **SV 进度偏差** | `SV = EV - PV` | `>0` 进度超前；`<0` 进度滞后 |
| **CPI 成本绩效指数** | `CPI = EV / AC` | `>1` 成本节约；`<1` 成本超支 |
| **SPI 进度绩效指数** | `SPI = EV / PV` | `>1` 进度超前；`<1` 进度滞后 |

口诀：**偏差 >0 好，指数 >1 好**；CPI/SPI 是"**每花 1 元/每计划 1 元，实际挣回多少**"。

## 2.3 预测四件套（P20 表 + 讲义 P162）
| 指标 | 公式 | 说明 |
|---|---|---|
| **BAC** | `BAC = 总 PV` | 完工预算（总计划价值） |
| **ETC 完工尚需** | 非典型：`ETC = BAC - EV`；典型：`ETC = (BAC - EV) / CPI` | 还需花多少 |
| **EAC 完工估算** | 通用：`EAC = AC + ETC`；非典型：`EAC = AC + (BAC - EV)`；典型：`EAC = BAC / CPI`；双因素：`EAC = AC + (BAC - EV) / (CPI × SPI)` | 总共要花多少 |
| **VAC 完工偏差** | `VAC = BAC - EAC` | `>0` 计划之内；`=0` 刚好；`<0` 计划之外 |
| **TCPI 完工尚需绩效指数** | 按原预算：`TCPI = (BAC - EV) / (BAC - AC)`；按新估算：`TCPI = (BAC - EV) / (EAC - AC)` | `>1` 很难完成；`=1` 正好完成；`<1` 很容易完成 |

## 2.4 典型 vs 非典型：靠题干关键词判断（P21 原话）
| 判断 | 关键词 | 用哪套公式 |
|---|---|---|
| **典型偏差 = 不纠偏** | "按此进度""按当前项目进展""按照当前绩效情况（继续进行）""偏差会持续下去""当前状态代表了未来的执行情况""以后的实施过程一直存在" | `ETC=(BAC-EV)/CPI`、`EAC=BAC/CPI` |
| **非典型偏差 = 纠偏** | "后续不再发生偏差""后续不会发生类似问题""以后的实施过程不再发生""按原计划执行" | `ETC=BAC-EV`、`EAC=AC+(BAC-EV)` |

## 2.5 挣值计算四步（表格式大题标准动作）
1. **先补全表**：逐行算 `EV = 完成% × 该活动预算`，再纵向汇总 PV、EV、AC。
2. **算四个指标**：CV、SV、CPI、SPI（保留两位小数）。
3. **判断状态**：CPI<1 成本超支、SPI<1 进度滞后（两个要分开说）。
4. **按题意预测**：题目给"典型/非典型"关键词 → 选 ETC/EAC/VAC/TCPI 公式。

**例题复算**（P22）：活动1 预算 800/100%/AC700；活动2 10000/90%/AC10000；活动3 20000/60%/AC16000
→ EV=800+9000+12000=21800；PV=30800；AC=26700 → **CPI=0.82（超支）、SPI=0.71（滞后）**。

## 2.6 六个陷阱
1. **EV 用实际单价**（错，必须用计划单价）。
2. **把 AC 当 PV** 代入 SPI → SPI 必须用 PV。
3. 题目说"**进度偏差为 0**"就以为成本也 0（错，SV=0 只说明进度符合计划；**完工时 SV 必然=0**，但 CV 不一定）。
4. TCPI 分母混用：按 BAC 完工用 `(BAC-AC)`，按 EAC 完工用 `(EAC-AC)`。
5. **ETC 与 EAC 混用**：ETC 是"还需"，EAC 是"总共"。
6. 双因素公式只在题干出现"**CPI 与 SPI 同时影响**"时才用。

# 篇三 进度+成本综合（P41–P63）

**题型**：给一张"活动/预算/完成%/AC"表 + 网络图，问偏差、预测、以及"如何赶工"。

**标准七步**：
1. 先算表内 EV（完成%×预算），汇总 PV/EV/AC。
2. 算 CPI、SPI、CV、SV → 判断成本与进度状态。
3. 用网络图算关键路径与总工期（顺推取大、逆推取小）。
4. 若有"典型/非典型"字样 → 算 ETC、EAC、VAC。
5. 若问"能否按预算完工" → 算 TCPI 与 1 比较。
6. 若问"如何压缩工期" → 只压关键路径、选单位成本最低、压后重算。
7. 结论句：一句成本、一句进度、一句建议。

# 篇四 其他领域计算（P64–P71）

## 4.1 三点估算 / PERT（P64–P65）
| 分布 | 期望值 | 标准差 |
|---|---|---|
| **β（贝塔）分布**（PERT 默认） | `E = (O + 4M + P) / 6` | `σ = (P - O) / 6` |
| **三角分布**（题目明说"服从三角分布"） | `E = (O + M + P) / 3` | — |

- O=最乐观、M=最可能、P=最悲观。
- **概率区间（必背）**：`E±1σ` 约 **68.26%**；`E±2σ` 约 **95.46%**；`E±3σ` 约 **99.73%**。
- 反向题："95% 概率在几周到几周之间" → 直接 `E ± 2σ`（P65 第 9 题：E=53、方差 49→σ=7，答案 53±14＝39~67）。

## 4.2 预期货币价值 EMV / 决策树（P66–P68）
- 公式：`EMV = Σ(每种结果的概率 × 该结果的货币值)`。
- 决策树：**每个方案画一条枝**，先算各枝 EMV，**比较取大**；有投入的要**先减投入**再比。
- 常考"自研 vs 外包"：`EMV = 成功概率 × 成功收益 + 失败概率 × 失败赔偿(或0) − 成本`。
- 判断归属：EMV/决策树属**定量**风险分析（定性分析是概率影响矩阵）。

## 4.3 配置管理版本号（P69；答案 P99）
| 状态 | 版本号格式 | 要点 |
|---|---|---|
| **草稿** | `0.YZ` | YZ 范围 **01–99**，随完善递增；初值与增幅自定 |
| **正式** | `X.Y` | X 为 1–9 主版本，Y 为 0–9（如 1.1 → 正式） |
| **修改** | `X.YZ` | 修改中的中间版本 |

**巨坑**（P99 解析原话）：新项目的需求**从 V0.1 开始**，不能在公司旧项目 V3.0 基础上续编。

## 4.4 成本加激励费用合同（P70；答案 P99）
- **买方支付 = 目标成本 + 目标费用 ± 分担比例 × 偏差**
  - 实际 < 目标（节约）：`支付 = 目标成本 + 目标费用 − 节约额 × 买方分成比例`
  - 实际 > 目标（超支）：`支付 = 目标成本 + 目标费用 + 超支额 × 买方负担比例`
- **卖方利润 = 买方支付 − 实际成本**。
- 例题：目标成本 100、目标费用 10、7:3 分成 → 实际 90 时支付 `100+10-10×0.7=103`，利润 13；实际 110 时支付 `100+10+10×0.7=117`，利润 7。

## 4.5 资源管理排程（选做，P71；答案 P99–P100）
1. 列出每个活动的 **R1/R2/R3 需求量、已分配量、历时**。
2. 算 **尚需资源 = 需求量 − 已分配量**，再算"可用 − 已占用 = 剩余"。
3. **按资源约束排活动**：资源不够就等，等活动释放再上。
4. 输出**按周次分段的表**：`时间段 / 在做活动 / 占用资源 / 释放情况`。
5. 最后一段结束时间即**项目完工时间**（例题答案：7 周；0–2 周 P4、P2 并行，3–4 周 P1+P5，4–7 周 P3+P5）。

# 一页速记（考前 5 分钟）
- 进度：`TF=LS-ES=LF-EF`；`FF=min(紧后ES)-EF`；关键活动 TF=FF=0；顺推取大、逆推取小。
- 路径：**最长路径=关键路径**，其长度=总工期。
- 挣值：`CV=EV-AC`、`SV=EV-PV`、`CPI=EV/AC`、`SPI=EV/PV`；偏差 >0 好、指数 >1 好。
- 预测：非典型 `EAC=AC+BAC-EV`；典型 `EAC=BAC/CPI`；`VAC=BAC-EAC`；`TCPI=(BAC-EV)/(BAC-AC)`。
- 三点：β `(O+4M+P)/6`、`σ=(P-O)/6`；三角 `(O+M+P)/3`；1σ 68.26%、2σ 95.46%、3σ 99.73%。
- 配置：草稿 `0.YZ`、正式 `X.Y`、修改 `X.YZ`；新项目从 V0.1 起。
- 合同：`支付=目标成本+目标费用±分成×偏差`；`利润=支付-实际`。

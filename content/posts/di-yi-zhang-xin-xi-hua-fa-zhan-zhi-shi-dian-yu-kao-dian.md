## 一、信息与信息化（P3–P5）

### 1. 信息的概念（P3）

> **原文**：信息是确定性的增加。信息不是物质，也不是能量。

- 香农："信息是用来**消除随机不定性**的东西。"香农把热力学中的**熵**引入信息论。
- **熵**是系统**无序**程度的度量；**信息**与熵正好相反，是系统**有序**程度的度量，表现为**负熵**。
- 信息量公式（比特为单位）：
  $$H = -\sum P(x_i)\log_2 P(x_i)$$
  P 代表概率，H 代表用以消除系统不确定性所需的**信息量**，即以比特为单位的负熵。

- 信息的特征与质量：**客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性**（11 个"性"，只考"有没有"不考排序）。

**考法**：第 27 题（用汉字/图片/叫声表达小狗的信息）考的就是"信息可以依附于不同载体、可以变换"——即**依附性、变换性、传递性**。

### 2. 信息的质量属性（P3，★★★必背表）

| 质量属性 | 概念 | 记忆钩子 |
|---|---|---|
| **精确性** | 对事物状态描述的精确程度 | 准 |
| **完整性** | 对事物状态描述的全面程度，完整信息应包括所有重要事实 | 全 |
| **可靠性** | 信息的来源、采集方法、传输过程是可以信任的，符合预期 | 信 |
| **及时性** | 信息获得的时刻与事件发生的时刻的间隔长短 | 快 |
| **经济性** | 信息获取、传输带来的成本在可以接受的范围之内 | 省 |
| **可验证性** | 信息的主要质量属性可以被证实或者证伪的程度 | 验 |
| **安全性** | 信息生命周期中，信息可被非授权访问的可能性，可能性越小、安全性越高 | 安 |

> **考点（原文明确）**：信息具有价值，价值大小**决定于信息的质量**。对于**金融信息**而言，其最重要的特性是**安全性**；对于**经济与社会信息**而言，其最重要的特性是**及时性**。
> ★ 这两句是原题（第 7、34 题一类"说法错误"题的题眼），务必逐字记。

### 3. 信息的传输模型（P3，★★★）

```
信源 → 编码器 → 信道 → 译码器 → 信宿
         ↑噪声（干扰）
```

| 部件 | 原文要点 |
|---|---|
| **信源** | 产生信息的实体，信息产生后由这个实体向外传播 |
| **编码器** | 如量化器、压缩编码器、调制器等；在编码阶段，信息被封装为 **TCP/IP 包**，**加密设备在信息编码阶段实现**；为了提高可靠性，编码时可以增加**冗余编码** |
| **信道** | 传送信息的通道，如 **TCP/IP 网络** |
| **噪声** | 干扰，包括信道中的噪声及分散在通信系统中的其他噪声的集中表示 |
| **译码器** | 包括解调器、译码器、数模转换器等 |
| **信宿** | 信息的归宿和接受者 |

**易错**：加密发生在**编码阶段**（不是传输阶段）；可靠性靠**冗余编码**；噪声是"干扰"的集中表示。

### 4. 信息系统及特征（P4）

- **系统的主要特性**（9 个）：目的性、整体性、层次性、稳定性、突变性、自组织性、相似性、相关性、环境适应性。
- **信息系统 = 管理模型 + 信息处理模型 + 系统实现条件**：
  - **管理模型**：系统服务对象领域的专门知识，以及分析和处理该领域问题的模型，又称**对象的处理模型**；
  - **信息处理模型**：系统处理信息的结构和方法——把管理模型中的理论和分析方法转化为**信息获取、存储、传输、加工和使用**的规则；
  - **系统实现条件**：可供应用的计算机技术和通信技术、从事对象领域工作的人员，以及对这些资源的控制与融合。
- **组成部件**：硬件、软件、数据库、网络、存储设备、感知设备、外设、人员、规程。
- **按用途类型划分**：电子商务系统、事务处理系统、管理信息系统、生产制造系统、电子政务系统、决策支持系统。

**信息系统的三大特征（P4，必背）**：

| 特性 | 概念 |
|---|---|
| **脆弱性** | 与系统的稳定性相对应，系统可能存在着丧失结构、功能、秩序的特性 |
| **开放性** | 系统的**可访问性**；决定系统可被外部环境识别，外部环境或其他系统可按预定方法使用系统功能或影响系统行为 |
| **健壮性** | 能够抵御出现**非预期状态**的特性，也叫**鲁棒性** |

### 5. 信息系统的生命周期（P4–P5，★★★★必考）

软件生命周期：可行性分析与项目开发计划 → 需求分析 → 概要设计 → 详细设计 → 编码 → 测试 → 维护。

**信息系统生命周期（简化 5 阶段）**：

| 阶段 | 别称 | 核心任务（原文关键词） | 成果文档 |
|---|---|---|---|
| **系统规划阶段** | — | 初步调查组织环境/目标/现状；确定信息系统发展战略；对建设新系统需求做出分析和预测；考虑各种约束；研究**必要性和可能性**；给出**备选方案**；进行**可行性研究**；编写**可行性研究报告**；审议通过后编写**系统设计任务书** | 可行性研究报告、系统设计任务书 |
| **系统分析阶段** | **逻辑设计阶段** | 依据系统设计任务书确定的范围详细调查；描述现行系统业务流程；指出局限性和不足；确定新系统**基本目标和逻辑功能要求**；提出**新系统的逻辑模型**；回答**"做什么"** | **系统说明书** |
| **系统设计阶段** | **物理设计阶段** | 依据系统说明书规定的功能要求，考虑实际条件，**具体设计实现逻辑模型的技术方案**；回答**"怎么做"**；分**总体设计（概要设计）**和**详细设计** | **系统设计说明书** |
| **系统实施阶段** | — | 计算机等设备购置、安装和调试；程序编写和调试；人员培训；数据文件转换；系统调试与转换 | **系统测试分析报告** |
| **系统运行和维护阶段** | — | 经常维护和评价；记录系统运行情况；按规则修改；评价系统工作质量和经济效益 | — |

> **三句话锁死**：规划答"要不要做"、分析答**"做什么"**、设计答**"怎么做"**、实施是"做出来"、运维是"养起来"。
> **第 73 题**：给"根据系统说明书规定的功能要求，考虑实际条件，具体设计实现逻辑模型的技术方案"→ **系统设计阶段**。
> **第 23 题**："开发阶段不包括（ ）"→ 开发＝分析＋设计＋实施，**规划、运维不算开发**。
> **第 32/82 题**：简化为**系统规划、系统分析、系统设计、系统实施、系统运行和维护**（5 个，不多不少）。

### 7. 信息化趋势（P6）

- **组织信息化趋势**：呈现产品信息化、产业信息化、社会生活信息化、国民经济信息化等趋势和方向。
- **国家信息化三步走**：
  1. **到 2020 年**：核心关键技术部分领域达到国际先进水平，信息产业国际竞争力大幅提升，信息化成为驱动现代化建设的**先导力量**；
  2. **到 2025 年**：国际领先的移动通信网络，根本改变核心关键技术受制于人的局面，实现**技术先进、产业发达、应用领先、网络安全坚不可摧**，涌现一批具有强大国际竞争力的大型跨国网信企业；
  3. **到 21 世纪中叶**：信息化全面支撑富强民主文明和谐的社会主义现代化国家建设，**网络强国**地位日益巩固。
- **《"十四五"国家信息化规划》十项体系**（记"6 个体系 + 2 个服务 + 2 个合作/治理"）：泛在智联的数字基础设施体系、高效利用的**数据要素**资源体系、释放数字生产力的创新发展体系、先进安全的数字产业体系、产业数字化转型发展体系、共建共治共享的数字社会治理体系、协同高效的数字政府服务体系、普惠便捷的数字民生保障体系、互利共赢的数字领域国际合作体系、规范有序的数字化发展治理体系。
- **今后一段时期发展重点**：**数据治理、密码区块链技术、信息互联互通、智能网联、网络安全**。

## 二、现代化基础设施（P6–P8）

### 1. 新型基础设施建设（新基建）（P6，★★★★）

- **基础设施**：交通、能源、水利、物流等传统基础设施，和以**信息网络**为核心的新型基础设施，在国家发展全局中具有**战略性、基础性、先导性**作用。
- **新型基础设施定义**：以**新发展理念**为引领，以**技术创新**为驱动，以**信息网络**为基础，面向高质量发展需要，提供**数字转型、智能升级、融合创新**等服务的基础设施体系。
- **七大领域**：**5G 基建、特高压、城际高速铁路和城际轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网**。

**新型基础设施三个方面（★★★表）**：

| 类别 | 别称 | 包含 |
|---|---|---|
| **信息基础设施** | **"技术新"** | ①通信网络基础设施：5G、物联网、工业互联网、卫星互联网；②新技术基础设施：人工智能、云计算、区块链；③算力基础设施：**数据中心、智能计算中心** |
| **融合基础设施** | **"应用新"** | 深度应用互联网、大数据、人工智能等技术，支撑传统基础设施转型升级 → 智能交通基础设施、智慧能源基础设施等 |
| **创新基础设施** | **"平台新"** | 支撑科学研究、技术开发、产品研制的具有**公益属性**的基础设施 → 重大科技基础设施、科教基础设施、产业技术创新基础设施等 |

> ★ **口诀："信息技术，应用融合，创新平台"**（信息=技术新、融合=应用新、创新=平台新）。
> **第 11 题**：不属于信息基础设施 → 常给"智慧能源"（属融合）或"科教基础设施"（属创新）。
> **第 39 题**：属于**算力基础设施** → **智能计算中心/数据中心**（不是 5G、不是区块链）。
> **第 17 题**：支撑科研、技术开发、产品研制、公益属性 → **创新基础设施**。
> **第 40 题**：支撑传统基础设施转型升级 → **融合基础设施**。
> **第 80 题**：属于融合基础设施 → **智能交通/智慧能源**。

### 2. 工业互联网（P7–P8，★★★★）

**内涵和外延**：工业互联网不是互联网在工业的简单应用，具有更丰富的内涵和外延。它既是工业**数字化、网络化、智能化**转型的**基础设施**，也是互联网、大数据、人工智能与实体经济深度融合的**应用模式**，同时也是一种**新业态、新产业**，将重塑企业形态、供应链和产业链。

**平台体系四大层级**：**以网络为基础，平台为中枢，数据为要素，安全为保障**。

**（1）网络是基础**——网络体系三部分：

| 部分 | 内容 |
|---|---|
| **网络互联** | 实现要素之间的数据传输，包括**企业外网和企业内网**；典型技术：传统工业总线、工业以太网、**时间敏感网络（TSN）**、确定性网络、5G |
| **数据互通** | 通过对数据**标准化描述和统一建模**，实现要素之间传输信息的相互理解；涉及数据传输、数据语义语法等层面 |
| **标识解析** | 实现要素的**标记、管理和定位**；由**标识编码、标识解析系统、标识数据服务**组成；为物料/机器/产品等物理资源和工序/软件/模型/数据等虚拟资源分配标识编码 |

**（2）平台是中枢**——平台体系四层：**边缘层、IaaS、PaaS、SaaS**，相当于工业互联网的"操作系统"，四大作用：

| 作用 | 内容 |
|---|---|
| **数据汇聚** | 网络层面采集的多源、异构、海量数据传输至平台，为深度分析和应用提供基础 |
| **建模分析** | 提供大数据、AI 分析的算法模型和物理、化学等仿真工具，结合**数字孪生**、工业智能等技术挖掘分析，实现数据驱动的科学决策和智能应用 |
| **知识复用** | 将工业经验知识转化为平台上的**模型库、知识库**，通过工业微服务组件方式，方便二次开发和重复调用 |
| **应用创新** | 面向研发设计、设备管理、企业运营、资源调度等场景提供各类**工业 App**、微服务组件等，帮企业提质增效 |

**（4）数据价值化（P12，★★★）**

> 以**数据资源化**为起点，三个要素构成"**三化**"框架：**数据资源化、数据资产化、数据资本化**。

| 三化 | 说明 | 本质 |
|---|---|---|
| **数据资源化** | 使无序、混乱的原始数据成为有序、有使用价值的数据资源（采集、整理、聚合、分析），形成"可采、可见、标准、互通、可信"的高质量数据资源 | 激发数据价值的**基础**，本质是**提升数据质量**，形成数据**使用价值** |
| **数据资产化** | 数据通过流通交易给使用者或所有者带来经济利益的过程 | 实现数据价值的**核心**，本质是形成数据**交换价值** |
| **数据资本化** | 两种方式：**数据信贷融资**与**数据证券化** | 拓展数据价值的**途径**，本质是实现数据要素**社会化配置** |

## 五、数字化转型与元宇宙（P15–P16）

### 1. 数字化转型（P15，★★★★）

- 定位：信息空间成长为**第三空间**，与**物理空间、社会空间**共同构成人类社会的**元空间**。
- 定义：建立在**数字化转换、数字化升级**基础上，进一步**触及组织核心业务**，以**新建立一种业务模式**为目标的高层次转型。
- **四个驱动因素**：

| 驱动因素 | 内容 |
|---|---|
| **生产力飞升** | 第四次科技革命 |
| **生产要素变化** | **数据要素**的诞生 |
| **信息传播效率突破** | **永生性、无限性、即时性、方向性** |
| **社会"智慧主体"规模** | 快速复制与"智能+" |

- **基本原理**：揭示个体智慧由"自然人"个体转移到**组织智慧**（计算机、信息系统等掌握的）的必要性和重要性，这种转移称"**智慧转移**"（也称"智慧移植"）。
- **DIKW 模型**：诠释**数据、信息、知识、智慧**之间的关系及转化过程与方法。
- **S8D 模型**：基于 DIKW 模型，构筑"**智慧—数据**""**数据—智慧**"两大过程的 **8 个转化活动**：

| 方向 | 四个活动 | 作用 |
|---|---|---|
| **智慧→数据** | **智慧结构化** | 明确业务体系层面的内容 |
| | **知识模型化** | 定义业务活动的逻辑关系 |
| | **过程信息化**（管理和工艺流程化） | 明确各执行操作系列要求 |
| | **数据平台化** | 实现数据的采集、存储和共享 |
| **数据→智慧** | **对象数字化** | 对各类对象进行数字化表达 |
| | **孪生虚拟化** | 完成**物理对象到信息空间的映射** |
| | **架构可视化** | 实现业务知识模型与经验沉淀的复用和创新 |
| | **计算智能化** | 实现多元条件下的调度和决策 |

> **第 1 题**："通过（ ）完成物理对象到信息空间的映射"→ **孪生虚拟化**（属"数据→智慧"）。
> **第 63 题**：组织能力数字化转型及持续迭代参考模型（**CPSD 模型**）不包括 → 四项活动为：**信息物理世界（CPS）建设、决策能力边际化（PtoE）部署、科学社会物理赛博（CPSS）构筑、数字框架与信息调制（DFIM）设计**。四项活动可从任一活动开始，形成持续迭代闭环。
> **第 79 题**：能力因子数字化转型的持续迭代包含上述四项活动（对应 CPS/PtoE/CPSS/DFIM）。

### 2. 元宇宙（P16，★★★★）

- 定义：利用科技手段进行链接与创造的，与现实世界**映射与交互**的**虚拟世界**，具备**新型社会体系**的数字生活空间；是整合多种新技术而产生的**新型虚实相融**的互联网应用和社会形态——基于**扩展现实（XR）**提供沉浸式体验，用**数字孪生**生成现实世界的镜像，通过**区块链**搭建经济体系，将虚拟世界与现实世界在**经济系统、社交系统、身份系统**上密切融合，允许每个用户进行内容生产和编辑。
- **四大特征（口诀"经理身体"）**：

| 特征 | 说明 |
|---|---|
| **沉浸式体验** | 基于人们对互联网体验的需求，即**即时信息基础上的沉浸式体验** |
| **虚拟身份** | 账号的内涵外延进一步丰富，发展为数字身份，即数字世界的一个或一组角色 |
| **虚拟经济** | 虚拟身份促使元宇宙具备开展虚拟社会活动的能力，这些活动需要一定经济模式展开 |
| **虚拟社会治理** | 元宇宙的经济与社会活动也需要法律法规和规则约束，需要**社区化的社会治理** |

> **第 4/65 题**：元宇宙特征不包含"虚拟现实""数字孪生"（那是技术），四大特征是**沉浸式体验、虚拟身份、虚拟经济、虚拟社会治理**。

## 七、陷阱清单（20 条，按题号整理）

1. **金融信息最重要特性＝安全性；经济与社会信息＝及时性**（P3 原句）。
2. 加密在**编码阶段**完成；可靠性靠**冗余编码**（P3）。
3. 信息系统三大特征：**脆弱性、开放性、健壮性（鲁棒性）**——不是"安全性/可靠性"。
4. 生命周期：**规划答"要不要"、分析答"做什么"、设计答"怎么做"**（第 73 题）。
5. 分析阶段成果是**系统说明书**；设计阶段是**系统设计说明书**；实施后是**系统测试分析报告**。
6. 信息化内涵 4 项：信息网络体系、信息产业基础、社会运行环境、效用积累过程（**不含"信息安全体系"**）。
7. 六要素：**资源=核心任务/重要标志，网络=基础设施，技术应用=龙头/主阵地，技术和产业=物质基础，人才=成功之本，政策法规=根本保障**（第 33/67/68/71 题）。
8. 三网融合＝**电信网、广播电视网、计算机网**。
9. 新基建七大领域**不含"特高压以外的电网""城市轨道交通以外的地铁"**之类混淆项；七大领域原文见 P6。
10. 算力基础设施＝**数据中心、智能计算中心**（第 39 题）；**区块链属新技术基础设施**。
11. 创新基础设施的判据＝**公益属性 + 支撑科研/技术开发/产品研制**（第 17 题）。
12. 工业互联网四层级：**网络为基础、平台为中枢、数据为要素、安全为保障**（第 43/75/76 题）。
13. 网络体系只有三部分：**网络互联、数据互通、标识解析**（第 10/44 题）。
14. 平台四作用：**数据汇聚、建模分析、知识复用、应用创新**。
15. 两化融合四方面：**技术、产品、业务、产业衍生**（不是"产业融合"）。
16. 智能制造五功能：**自感知、自学习、自决策、自执行、自适应**（第 48 题）。
17. 数据价值化起点＝**数据资源化**（第 7/15 题）。
18. 数字化治理核心特征＝**数据互通 + 全面协同 + 跨部门流程再造**；关键词"用数据说话/决策/管理/创新"。
19. 智慧城市五能力：**数据治理、数字孪生、边际决策、多元融合、态势感知**（第 21 题）。
20. 元宇宙四特征：**沉浸式体验、虚拟身份、虚拟经济、虚拟社会治理**（第 4/65 题）。

## 三、知识点精讲

### 1. 制定项目章程：定义、三大作用、一次性（P108）★第 1、3、22 题

- **定义**：制定项目章程是编写一份**正式批准项目**并**授权项目经理在项目活动中使用组织资源**的文件的过程。
- **三大作用**（背下来，选择题原话考）：
  1. 明确项目与**组织战略目标**之间的直接联系；
  2. 确立项目的**正式地位**；
  3. 展示组织对项目的**承诺**。
- **开展频次**：本过程**仅开展一次**，或仅在项目的**预定义**时开展（第 22 题选 B 的依据；凡是说"可以在项目进展过程中持续完善或多次开展"的都错）。
- **输入**：①项目立项文件（项目建议书、可行性研究报告、项目评估报告）②协议（合同、口头协议、意向书等书面协议）③事业环境因素 ④组织过程资产。
- **工具与技术**：专家判断；数据收集（头脑风暴、焦点小组、访谈）；人际关系与团队技能（冲突管理、引导、会议管理）；会议。
- **输出**：**项目章程、假设日志**。

### 2. 项目章程包含什么、不包含什么（P108）★第 1、3 题

讲义 P108 列的 11 条（顺序可记成"目的—目标—需求—风险—里程碑—钱—人—审批—退出—授权—签发人"）：

1. 项目目的；
2. 可测量的项目目标和相关的成功标准；
3. 高层级需求、高层级项目描述、边界定义以及主要可交付成果；
4. 整体项目风险；
5. 总体里程碑进度计划；
6. 预先批准的财务资源；
7. 关键干系人名单；
8. 项目审批要求（评价项目成功的标准、由谁对项目成功下结论、由谁签署项目结束）；
9. 项目退出标准；
10. 委派的项目经理及其职责和职权；
11. 发起人或其他批准项目章程的人员的姓名和职权。

**不包含**（这是本章最爱设的坑）：
- **需求跟踪矩阵**（第 1 题 D）——它是**收集需求**的输出；
- **进度基准、成本基准、范围基准**（第 3 题 ⑤⑥）——基准是**项目管理计划**的内容；
- 详细的产品功能/技术方案。

> 第 3 题：章程主要内容＝①②③④（项目目的或批准理由、主要风险、总体预算、总体里程碑进度计划）→ B。
> 记忆钩子：**"章程写'高层级'，计划写'基准'。"**

### 3. 章程的三条"权责铁律"（P108）★第 2、5、6、23 题，最易混

| 问题 | 答案 | 讲义/答案解析原文 |
|---|---|---|
| 谁**发布/签发**章程？ | **项目以外的实体**：发起人、项目集、PMO、项目组合治理委员会主席或其授权代表 | "项目由项目以外的机构来启动" |
| 谁**编制**章程？ | **发起人**编制，或**项目经理与发起机构合作**编制 | P108 |
| 谁有权**修改**章程？ | **只有管理层和发起人**（遵循"谁签发，谁有权修改"） | 05 P47 解析 |
| 项目经理能做什么？ | 可以**参与甚至起草**章程，但**不能发布、不能修改** | 同上 |
| 章程能当合同吗？ | **不能**。执行外部项目时靠正式合同达成合作；章程用于建立**组织内部**的合作关系 | P108 + 05 P48 解析 |

- 第 **2** 题：说"章程由项目经理发布"是错的 → **B**。
- 第 **6** 题：说"项目经理有权修改章程"是错的 → **D**。
- 第 **5** 题（你做对了）：章程**不能替代合同** → C。
- 第 **23** 题（空题）：外部项目用合同合作，**但仍需要**章程来建立组织内部合作关系，A 说"不需要"所以错 → **A**。

**记忆钩子**：**"项目经理只能起草，签发归发起人，修改归管理层和发起人。"**

### 4. 章程的其他要点（P108）★第 5、7、22、28 题

- **章程一旦被批准，就标志着项目的正式启动**。
- **应在规划开始之前任命项目经理，越早越好，最好在制定章程时就任命**。
- 章程**授权**项目经理进行规划、执行和控制，并授权其在项目活动中使用组织资源。
- **章程是制订项目管理计划的输入**，所以项目管理计划**不可能**是章程的依据（第 7 题选 B）。
- 制订项目管理计划时，项目团队把**项目章程**作为**初始项目规划的起点**（第 28 题 B）。

### 5. 识别干系人：定义与时点（P109）★第 10、14 题

- **定义**：识别干系人是**定期**识别项目干系人，分析和记录他们的**利益、参与度、相互依赖性、影响力和对项目成功的潜在影响**的过程。
- **作用**：使项目团队能够建立对每个干系人或干系人群体的**适度关注**。
- **开展频次**：应根据需要**在整个项目期间定期开展**（第 14 题 A 对）；通常在**编制和批准项目章程之前或同时**首次开展，之后在项目生命周期中必要时重复开展。
- 第 **10** 题：A 说"在项目**立项**时进行"是错的——正确说法是"在项目**启动**时"，且要贯穿全过程 → **A**。
- 第 **14** 题（你做对了）：选"需要在整个项目期间定期开展"（A）。

### 7. 干系人分类的 5 种数据表现（P109–P110）★第 9、16、26、31 题

| 模型 | 适用/说明 |
|---|---|
| **作用影响方格**（权力-利益方格、权力-影响方格） | 基于权力、利益、影响、改变计划的能力；适用于**小型、简单**项目 |
| **干系人立方体** | 把方格要素组合成**三维模型**（多维模型），助于制定沟通策略 |
| **凸显模型** | 评估**权力、紧迫性、合法性**（可用邻近性取代合法性）；适用于**复杂的干系人大型群体**（第 16 题 C） |
| **影响方向** | 向上/向下/向外/横向（见下节） |
| **优先级排序** | 干系人多、成员频繁变化、关系复杂时才需要 |

- 第 **9** 题：常用分类方法**不包括**"影响/意愿方格" → D。
- 第 **26** 题：问"**分析技术**"，只有**干系人分析、文件分析**；立方体、方格属**数据表现** → C。
- 第 **31** 题（你做对了）：**权力-利益矩阵**是干系人识别与分类的核心工具 → A。
- 第 **16** 题（你做对了）：复杂大型群体用**凸显模型** → C。

### 8. 影响方向四分类（P110）★第 18、19、20 题

| 方向 | 指谁 |
|---|---|
| **向上** | 执行组织或客户组织、发起人和指导委员会的**高级管理层** |
| **向下** | **临时贡献知识或技能**的团队或专家（项目团队成员） |
| **向外** | 项目团队**之外**的干系人群体及代表：供应商、政府机构、公众、最终用户、监管部门 |
| **横向** | 项目经理的**同级人员**（其他项目经理、中层管理人员），与项目经理竞争稀缺资源 |

- 第 **18** 题（对）：高管层 → 向上（A）。
- 第 **19** 题（对）：临时贡献知识或技能的团队或专家 → 向下（B）。
- 第 **20** 题：同级人员 → **横向（D）**，你选了向外。

**记忆钩子**：**"上领导、下干活、外供应商、横同级。"**

### 9. 干系人登记册（P110）★第 21、27 题

三块内容：
1. **基本信息**：姓名、组织职位、地点、联系方式、在项目中扮演的角色；
2. **评估信息**：主要需求、期望、对项目成果的潜在影响、最能影响或冲击的项目生命周期阶段；
3. **干系人分类**：内部/外部；作用、影响、权力或利益；上级/下级/外围/横向；或项目经理选择的其他分类模型的结果。

- 第 **21** 题（对）：登记册**不含**"隐私信息" → C。
- 第 **27** 题（对）：干系人联系方式需要补充修正时，改的是**干系人登记册** → A。

### 10. 项目启动会议（P110）★第 24、25 题

- **谁组织**：由**项目经理**负责组织和召开，标志对项目经理责权的定义结果的正式公布。
- **目的**：使各方干系人明确项目的**目标、范围、需求、背景**及各自的**职责与权限**，并**正式公布项目章程**。
- **5 个工作步骤**（第 24 题考"不包含"）：
  1. 确定会议目标（建立初始沟通、相互了解、获得支持、对建设方案达成共识）；
  2. 会议准备（审阅文件、启动准备会议、明确关键议题、编制初步计划等）；
  3. 识别参会人员（**由项目经理主持**；参会含发起人、组织高层领导、客户及用户代表、资源和职能部门负责人）；
  4. 明确议题（开发过程、产出物、资源与进度计划）；
  5. 进行会议记录。
- 第 **24** 题：步骤里**没有**"识别项目目标和价值" → C。
- 第 **25** 题：主持人＝**项目经理（D）**，不是发起人。

### 11. 关注价值和目标（P111）★第 29 题

- **在项目启动阶段需根据"项目预期价值的实现"识别项目的目标**，项目目标包括**成果性目标**和**约束性目标**。
- PMI 定义**商业价值**＝从商业运作中获得的**可量化净效益**；在商业分析中，商业价值可视为"回报"（以某种投入换取时间、资金、货物或无形回报）。
- **项目价值是项目建设的最终衡量依据**，应作为项目管理与监控的重要指导依据，在项目策划与监控过程中实时监控。
- 第 **29** 题：启动阶段识别目标依据 → **项目预期价值的实现（D）**，不是项目章程。

### 12. 干系人参与类型：领导型／支持型／抵制型（05 P49）★第 32 题

- **领导型**：积极参与项目，**主动推动**项目进展，以确保项目成功；
- **支持型**：知晓项目并支持项目工作（不强调主动推动）；
- **抵制型**：知晓项目但**持反对态度**，可能阻碍项目推进。

第 32 题前半句强调"**积极参与，以确保项目取得成功**"，对应"领导型"，所以选 **A**。你选的 B（支持型）是"只支持不推动"，差点意思——**题干出现"以确保成功/主动推动"就选领导型**。

## 四、易混对比（考前扫一眼）

| 对比 | 左边 | 右边 | 判据 |
|---|---|---|---|
| 章程 vs 项目管理计划 | 章程：批准项目、授权项目经理、高层级 | 计划：基准（范围/进度/成本）、详细 | 章程在前，计划在后；计划不能是章程的依据 |
| 谁签发 vs 谁修改 | 签发：发起人/PMO 等**项目外实体** | 修改：管理层和**发起人** | "谁签发谁有权修改"，都不关项目经理 |
| 章程 vs 合同 | 章程：建立**组织内部**合作关系 | 合同：外部合作、法律效力 | 外部项目两者都要，不能互相替代 |
| 数据分析 vs 数据表现 | 分析：**干系人分析、文件分析** | 表现：方格、立方体、凸显模型、影响方向、优先级排序 | 问"分析技术"只答前两个 |
| 立方体 vs 凸显模型 vs 方格 | 方格：小项目 | 立方体：多维 | 凸显：复杂大群体（权力/紧迫性/合法性） |
| 向上/向下/向外/横向 | 上＝高管；下＝贡献知识的团队专家 | 外＝供应商政府公众用户；横＝同级 | "同级"是最容易记反的 |
| 立项 vs 启动 | 立项：建议书、可研、评估（第九章） | 启动：章程 + 识别干系人（第十章） | 干系人分析在**启动**时开展 |

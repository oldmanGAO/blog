# 计算专题 知识点与考点

> **依据**：《26.10 计算专题》讲义全 100 页（第一篇 进度 P2–P19、第二篇 成本 P20–P40、第三篇 进度成本综合 P41–P63、第四篇 其他领域 P64–P71、参考答案 P72–P100）＋ 参考资料《中高项计算公式汇总》《十五至尊图》。
> **本书定位**：案例分析题的"计算分"与选择题的"计算分"全在这里。**四种必考题型**：①网络图与关键路径（含总时差/自由时差）②挣值管理 EVM（含 ETC/EAC/TCPI）③三点估算与 PERT 概率 ④EMV 决策树。**三种次高频**：⑤成本加激励合同 ⑥配置管理版本号 ⑦资源受限排程。
> **一条铁律**：**计算题必须写出公式和步骤**。答案算错但公式对，仍可能得步骤分；只写答案不写过程，错了就是 0 分。

## 〇 速查总表（先背这张）

| 题型 | 出现位置 | 核心公式 | 一句话记法 |
|---|---|---|---|
| 关键路径 | 选择/案例 | 路径长度相加取最大 | **正推取大，逆推取小** |
| 总时差 TF | 选择/案例 | TF = LS−ES = LF−EF | **下减上** |
| 自由时差 FF | 选择/案例 | FF = min(紧后 ES) − 本活动 EF | **后减前** |
| 提前量/滞后量 | 选择 | 提前 = 减，滞后 = 加 | **提前减、滞后加** |
| EVM 四指标 | 选择/案例 | PV、EV、AC、BAC | 应干/干了/花了/总预算 |
| 偏差与指数 | 案例必考 | CV=EV−AC；SV=EV−PV；CPI=EV/AC；SPI=EV/PV | **偏差 >0 好；指数 >1 好** |
| ETC/EAC | 案例必考 | 典型：ETC=(BAC−EV)/CPI、EAC=BAC/CPI；非典型：ETC=BAC−EV、EAC=AC+BAC−EV | **典型就是"照现在这样下去"** |
| TCPI | 选择 | 按 BAC：(BAC−EV)/(BAC−AC)；按 EAC：(BAC−EV)/(EAC−AC) | **>1 难，=1 正好，<1 易** |
| 三点估算 | 选择/案例 | β：(O+4M+P)/6；三角：(O+M+P)/3；σ=(P−O)/6 | **贝塔四倍中** |
| 概率区间 | 选择 | ±1σ 68.3%、±2σ 95.5%、±3σ 99.7% | **1-2-3 对应 68-95-99** |
| EMV | 选择/案例 | EMV = Σ(概率×损益) | **净利润口径要看清** |
| CPIF 合同 | 案例 | 卖方利润 = 目标费用 + 卖方分成×(目标成本−实际成本) | **省下的按比例分** |
| 版本号 | 选择 | 草稿 0.YZ；正式 X.Y；修改 X.YZ | **0 开头是草稿，第三位是修改** |

## 一、计算题的通用答题规范（案例计算题拿满分的前提）

1. **先写公式，再代数字，最后写结果**——三步分开写，每步都可能给分。
2. **保留小数位数按题目要求**；没要求就保留两位（中间过程多保留一位，避免累积误差）。
3. **结论必须"数值 + 判断"**：不能只写"CPI=0.82"，要写"CPI=0.82<1，成本超支"。
4. **单位统一**：题目给"万元"就全程万元，别混"元"。
5. **判断题要说明理由**：只写"×"往往只得一半分，要补一句为什么错。
6. **不会也要写**：把公式写上去、把已知数代进去，能拿步骤分。

## 二、进度计算（第一篇 P2–P19）

### 1. 活动依赖关系四型（P2，选择题常考）

| 类型 | 含义 | 例子 |
|---|---|---|
| **F-S（完成-开始）** | 前序活动**结束**，后续活动才能**开始** | 装配完硬件 → 开始装系统（默认关系，占 90%） |
| **F-F（完成-结束）** | 前序活动**结束**，后续活动才能**结束** | 文件全部编写完 → 文件编辑才能结束 |
| **S-S（开始-开始）** | 前序活动**开始**后，后续活动才能**开始** | 开始浇灌地基 → 开始混凝土找平 |
| **S-F（开始-结束）** | 前序活动**开始**后，后续活动才能**结束** | 新系统启动 → 旧系统才能关闭 |

> **考法**：给一句话问属于哪种依赖。"A 完成后 B 才能完成"=F-F；"B 的开始要等 A 开始"=S-S。

### 2. 六宫格与四个时间（P2，必须会画）

每个活动节点画成一个"六宫格"：

```
┌──────────┬──────────┬──────────┐
│  ES      │  工期 D  │  EF      │   ← 上排：最早开始 / 工期 / 最早完成
├──────────┴──────────┴──────────┤
│           活动名称              │
├──────────┬──────────┬──────────┤
│  LS      │  总时差  │  LF      │   ← 下排：最迟开始 / 总浮动 / 最迟完成
└──────────┴──────────┴──────────┘
```

四个时间的定义（P2 原文）：

- **ES（最早开始）**：某项活动能够开始的最早时间；
- **EF（最早完成）**：某项活动能够完成的最早时间；
- **LS（最迟开始）**：为使项目按时完成，活动**必须**开始的最迟时间；
- **LF（最迟完成）**：为使项目按时完成，活动**必须**完成的最迟时间。

计算公式（P120 讲义＋P2 计算专题）：

```
EF = ES + D
LS = LF − D
```

### 3. 总时差与自由时差（选择题第一高频，P2–P3）

- **总浮动时间（总时差 TF）**：此活动**最长可耽误而不影响总工期**的时间。
  **公式：TF = LF − EF = LS − ES**（口诀：**下减上**）

- **自由浮动时间（自由时差 FF）**：此活动**最长可耽误而不影响任何紧后活动最早开始**的时间。
  **公式：FF = min(所有紧后活动的 ES) − 本活动的 EF**（口诀：**后减前**）

- **关键活动的总时差与自由时差都为 0**（P5"温馨提示"）。

> **例题（P3）**：网络计划中工作 M 有两项紧后工作，其最早开始时间分别为第 12 天和第 15 天；M 的 ES=6、LS=8，工期 4 天。求 M 的总时差。
> **解**：TF = LS − ES = 8 − 6 = **2 天**（选 B）。注意题目给的紧后 ES 是干扰项——总时差**只用本活动自己的 LS/ES**；若要算自由时差才用 min(紧后 ES) − EF = 12 − 10 = 2。

> **易错**：总时差与自由时差混淆。判别口诀——**"影不影响总工期"看总时差，"影不影响紧后活动"看自由时差**。

### 4. 提前量与滞后量（P3）

- **提前量（Lead）**：紧后活动可以**提前**的时间量 → **提前量为减**（如 FS−14 表示提前 14 天）。
- **滞后量（Lag）**：紧后活动需要**推迟**的时间量 → **滞后量为加**（如 FS+180 表示推迟 180 天）。

> **例题（P3）**：H 与 I 之间标注"FS+10"，则含义是"**活动 H 开始 10 天后，开始活动 I**"？注意——FS+10 的准确含义是"H **完成**后 10 天，I 才开始"。讲义该题答案为 D（活动 H 开始 10 天后开始 I），是因为图中标注另有 S-S 关系，**做题时务必看清箭头连的是开始还是完成**。

### 5. 网络图两种画法（P4）

| 方法 | 别名 | 画法 | 特点 |
|---|---|---|---|
| **前导图法 PDM** | 单代号网络图 | **节点（方框）表示活动**，箭头表示逻辑关系 | 考试主流，易画 |
| **箭线图法 ADM** | 双代号网络图 | **箭线表示活动，节点表示事件** | 需引入**虚活动**表达依赖 |

**箭线图法四条规则**（P120）：①每个事件必须有唯一代号；②节点代号沿箭线方向越来越大；③流入（流出）同一节点的活动，均有共同的紧后活动（紧前活动）；④**虚活动不消耗时间，也不消耗资源**，只用于弥补箭线图表达依赖关系的不足。

### 6. 关键路径法（P4–P6，最重要）

**定义**：所有从开始到结束的路径中，**活动历时之和最大**的那条路径。
**总工期**：关键路径上活动历时之和 = **项目最短可能工期**。

**三条性质**（P5）：

1. 关键路径是项目中**时间最长的活动顺序**，决定可能的**最短工期**；
2. 关键路径上的活动叫**关键活动**；**可能有多条关键路径**（此时任何一条都不能单独用来"唯一确定"关键活动）；
3. 关键路径法还用于计算路径的**进度灵活性（浮动时间）**。

**计算口诀（P5"解题小锦囊"，原文）**：

> **顺推为上，必取大。逆推为下，必取小。**
> **自由浮动时间：后减前。总浮动时间：下减上。**
> **时间提前量为减，时间滞后量为加。**

**手算步骤**：

1. 正推：从起点开始，ES = 紧前 EF 的**最大值**；EF = ES + D（取大 → 得最早时间）；
2. 逆推：从终点倒推，LF = 紧后 LS 的**最小值**；LS = LF − D（取小 → 得最迟时间）；
3. 求各活动 TF = LS − ES；**TF = 0 的活动串起来就是关键路径**；
4. 总工期 = 终点节点的 EF。

> **例题（P5）**：A=1、B=2、C=3、D=4、E=7、F=4、G=6、H=6、I=2、J=3，路径为 A-D-H-J、B-E-H-J、B-F-J、C-G-I-J。
> 四条路径长度：1+4+6+3=**14**；2+7+6+3=**18**；2+4+3=**9**；3+6+2+3=**14**。
> 最长 18 → **关键路径 B-E-H-J，总工期 18 天**（选 D）。

> **陷阱**：题目给"活动历时"表格＋"紧前活动"列时，**必须先画网络图再算**，不能直接按表格顺序累加。路径列举法只适合活动少（≤10 个）的图。

### 7. 时标网络图读图（P1317 附近题目，选择/案例都可能考）

- 横轴为时间，箭线长度＝活动历时；
- 图上的**波浪线＝自由时差**；
- **某活动的总时差 = 从该活动到终点所有路径上波浪线长度之和的最小值**。

### 8. 资源平衡 vs 资源平滑（选择题高频）

| 项目 | **资源平衡（Leveling）** | **资源平滑（Smoothing）** |
|---|---|---|
| 针对资源 | **关键资源**（资源冲突导致无法按计划执行） | **非关键资源** |
| 是否改变关键路径 | **通常会改变** | **不改变** |
| 是否延长工期 | **通常延长总工期** | **不延长总工期** |
| 目的 | 解决资源超负荷/资源冲突 | 削峰填谷，使资源需求平稳 |

> **口诀**：**平衡动关键路径、要延期；平滑不动关键路径、不延期。**

### 9. 进度压缩两法（案例"如何缩短工期"必答）

| 方法 | 做法 | 代价 |
|---|---|---|
| **赶工（Crash）** | 增加资源（加班、加人）压缩**关键活动**历时 | **成本增加、风险增加**；只压"赶工成本最低"的关键活动 |
| **快速跟进（Fast Tracking）** | 把原本**顺序**进行的活动**并行** | **返工风险增加**、可能增加成本、可能降低质量 |

> **案例标准答案（P75）**：缩短工期可采取——①赶工；②快速跟进、并行施工；③使用高素质/经验更丰富的人员；④减小活动范围或降低活动要求；⑤改进方法或技术提高效率；⑥加强质量管理减少返工。

> **注意**：压缩工期**只能压关键路径上的活动**，压非关键活动对总工期无效（除非压到该活动变成关键活动）。

### 10. 三点估算与 PERT（第四篇 Part1，P64–P65）

**贝塔分布（默认，考试首选）**：

```
期望工期 TE = (O + 4M + P) / 6
标准差 σ = (P − O) / 6
方差 = σ²
```

**三角分布（题目明确说"服从三角分布"时才用）**：

```
TE = (O + M + P) / 3
```

其中 O＝最乐观、M＝最可能、P＝最悲观。

**概率区间（正态分布）**：

| 区间 | 概率 |
|---|---|
| TE ± 1σ | **68.3%**（讲义简写 68%） |
| TE ± 2σ | **95.5%**（简写 95%） |
| TE ± 3σ | **99.7%**（简写 99%） |
| 最小值 / 最大值 | TE − 3σ / TE + 3σ |

> **例题 1（P64 第 1 题）**：O=35、M=42、P=55 → TE=(35+4×42+55)/6=258/6=**43 天**（选 B）。
> **例题 2（P64 第 3 题）**：O=6、M=10、P=20 → σ=(20−6)/6=2.33≈**2.3 天**（选 C）。
> **例题 3（P65 第 9 题）**：期望 53 周、方差 49 → σ=7；95% 区间 = 53±2×7 = **39~67 周**（选 B）。
> **例题 4（P64 第 7 题）**：三角分布 (20+30+50)/3 = **33.3 天**（选 C）。

> **易错**：①"三个估算值"题目没说分布 → 默认 **β（贝塔）**；②标准差公式分子是 **(P−O)**，不是 (P−M) 或 (M−O)；③合并多个活动时，**期望相加、方差相加**（不是标准差相加）。

## 三、成本计算：挣值管理 EVM（第二篇 P20–P40，案例必考）

### 1. 十二个指标总表（P20 原表＋P162–P163 讲义）

| 缩写 | 中文 | 公式 | 结果解析 | 记忆 |
|---|---|---|---|---|
| **PV** | 计划值 | PV = 计划工作量 × 计划单价 | **应该干多少** | Plan |
| **EV** | 挣值 | EV = 实际工作量 × 计划单价 = 完成百分比 × PV | **干了多少** | Earned |
| **AC** | 实际成本 | 题目直接给出 | **花了多少** | Actual |
| **BAC** | 完工预算 | = 总 PV = 成本基准 | 原定总预算 | Budget |
| **CV** | 成本偏差 | **CV = EV − AC** | >0 成本节约，<0 成本超支 | **>0 好** |
| **SV** | 进度偏差 | **SV = EV − PV** | >0 进度超前，<0 进度落后 | **>0 好** |
| **CPI** | 成本绩效指数 | **CPI = EV / AC** | >1 节约，<1 超支 | **>1 好** |
| **SPI** | 进度绩效指数 | **SPI = EV / PV** | >1 超前，<1 落后 | **>1 好** |
| **ETC** | 完工尚需估算 | 典型：(BAC−EV)/CPI；非典型：BAC−EV | 还需花多少 | 剩余 |
| **EAC** | 完工估算 | 通用：AC + ETC | 总共要花多少 | 已花+还需 |
| **VAC** | 完工偏差 | VAC = BAC − EAC | >0 计划之内 | 余量 |
| **TCPI** | 完工尚需绩效指数 | 按 BAC：(BAC−EV)/(BAC−AC)；按 EAC：(BAC−EV)/(EAC−AC) | >1 很难，=1 正好，<1 容易 | 剩余钱干剩余活 |

> **注**：EV 必须与 PV 的口径对应——"已完成的实际工作量 × 计划单价"，**绝不能用实际单价**。

### 2. 典型偏差 vs 非典型偏差（案例第一判别题，P21）

**判别关键词（讲义原文）：**

| 类型 | 题目中的说法 | 应对 |
|---|---|---|
| **典型偏差（不纠偏）** | "按此进度""按当前项目进展""按照当前绩效情况（继续进行）""偏差会持续下去""当前状态代表未来执行情况""以后的实施过程一直存在" | **用 CPI 除**：ETC=(BAC−EV)/CPI，EAC=BAC/CPI |
| **非典型偏差（纠偏）** | "后续不再发生偏差""后续不会发生类似问题""以后的实施过程不再发生""按原计划执行" | **直接减**：ETC=BAC−EV，EAC=AC+BAC−EV |

> **口诀**：**典型＝"照这样下去"，要"除"；非典型＝"以后改正了"，只"减"。**

### 3. EAC 的四个公式（别混）

```
EAC = AC + ETC                       （通用公式，任何时候都对）
EAC = BAC / CPI                      （典型偏差）
EAC = AC + (BAC − EV)                （非典型偏差）
EAC = AC + (BAC − EV)/(CPI × SPI)    （进度和成本都影响剩余工作时）
```

> **判断"用哪个"**：题干出现"当前偏差继续""照此趋势"→ 第 2 式；"偏差不再发生""按原计划"→ 第 3 式；题干说"进度与成本绩效同时影响剩余工作"→ 第 4 式。**拿不准就写通用式 AC+ETC，并把 ETC 的算法写清楚**。

### 4. TCPI 两种口径（P163）

```
TCPI(按原预算完成) = (BAC − EV) / (BAC − AC)
TCPI(按新估算完成) = (BAC − EV) / (EAC − AC)
```
含义：**为了在剩余预算内完工，剩余工作必须达到的成本绩效水平**。>1 表示"必须比现在更省"（很难），=1 表示"保持现状即可"，<1 表示"可以放松"。

### 5. 综合题的"列表法"（案例计算题标准解法）

题目给一张"活动 / 预算 / 完成百分比 / AC"的表时，**先补两列再算**：

| 步骤 | 做法 |
|---|---|
| ① 求 PV | 把**计划应完成**的活动预算全部相加（注意"截至第 N 月应完成哪些活动"） |
| ② 求 EV | Σ(每个活动的预算 × 该活动完成百分比) |
| ③ 求 AC | 直接把表中实际成本相加（题目常直接给合计） |
| ④ 求 CV/SV | CV=EV−AC，SV=EV−PV |
| ⑤ 求 CPI/SPI | CPI=EV/AC，SPI=EV/PV |
| ⑥ 判断 | CPI<1 成本超支；SPI<1 进度落后；两者结论分别写 |
| ⑦ 预测 | 按典型/非典型算 ETC、EAC |

> **例题（P22）**：活动 1 预算 800、完成 100%、AC 700；活动 2 预算 10000、完成 90%、AC 10000；活动 3 预算 20000、完成 60%、AC 16000。
> PV = 800+10000+20000 = **30800**；EV = 800×100% + 10000×90% + 20000×60% = 800+9000+12000 = **21800**；AC = 700+10000+16000 = **26700**。
> CPI = 21800/26700 = **0.82**（成本超支）；SPI = 21800/30800 = **0.71**（进度滞后）→ 选 A。

> **例题（大表题，P23–P24 第 7 题）**：合计 PV=15000、AC=16000、EV=12800，BAC=50000，典型偏差 → EAC = BAC/CPI = 50000/(12800/16000) = 50000/0.8 = **62500 元**（选 D）。
> 这里的关键是**先用合计值求 CPI，再整体求 EAC**，不要逐个活动求 EAC 再相加。

### 6. 储备与成本基准（易错，P60–P61、P162）

```
成本基准（BAC）= 工作包成本估算 + 应急储备
项目预算 = 成本基准 + 管理储备
```
- **应急储备**：应对**已识别的风险（已知-未知）**，**包含在成本基准内**，项目经理可动用；
- **管理储备**：应对**未识别的风险（未知-未知）**，**不包含在成本基准内**，动用需**高层审批**；
- **BAC 只包含成本基准，不含管理储备**——所以"增加管理储备"**不改变 BAC**，只改变项目总预算。

> **必考陷阱**（P37 判断题）："管理储备主要应对'已知-未知'风险"→ **错**（那是应急储备）；"管理储备是成本基准的组成部分、不需高层审批"→ **错**。

**问题 1（6–10 分）**：计算监控点的 PV、EV、AC，求 CV、SV、CPI、SPI，判断绩效。

**问题 2（3–4 分）**：求 ETC、EAC。
> 答：①先写"典型/非典型"判断依据（引用题干原话）②写公式 ③代入 ④写结果。

> 答：从**成本超支怎么控**（加强成本控制、优化资源、减少返工、加强采购比价）＋**进度落后怎么赶**（赶工、快速跟进、加人、缩范围、改进方法、加强质量）两方向分点写。

### "按时间均匀分布"的 PV 求法

题干说"**假设活动成本/工作量在计划期内均匀分布**"时：
```
某活动到第 N 月的 PV = 该活动预算 × (第 N 月已过去的计划月数 / 该活动计划总月数)
```
> 例：某活动预算 300 万，计划第 2 月初至第 7 月末完工（6 个月），到第 7 月末 → PV=300×(6/6)=300。

### 题目二十的完整示例（P60，值得抄一遍）

已知 BAC=360，12 个活动，3 月底应完成 1–10 个活动，PV/AC/完成百分比表格给出。

- PV = 前 10 个活动的 PV 之和；EV = Σ(PV×完成百分比)；AC = 实际成本之和；
- 问题 1：CV、SV 并评估（分别写"成本节约/超支""进度提前/落后"）；
- 问题 2：①"当前项目不会再发生该状态"→**非典型**：ETC=BAC−EV，EAC=AC+ETC；②"当前项目持续该状态"→**典型**：ETC=(BAC−EV)/CPI，EAC=BAC/CPI；
- 问题 3：判断题——成本基准**不含**管理储备（×）；成本估算包含通货膨胀补贴、融资成本、应急成本（√）。

## 五、其他领域专项（第四篇 P64–P71）

### 1. EMV 与决策树（P66–P68，案例 5–6 分题）

**基本公式**：
```
EMV = Σ (概率 × 损益)
决策原则：选 EMV 最大的方案（若全部为负，选亏损最小的）
```

**口径要看清楚**：题目给的是"收入"还是"利润"。

- 若给**收入**和**投资/成本**：EMV = Σ[概率 × (收入 − 成本)]；
- 若给"成功后获利"：直接用获利金额；
- 若给"失败赔偿"：失败分支 = −(成本 − 赔偿)。

> **例题（P66 第 2 题，决策树）**：
> 方案 A（投入 120 万）：强需求 70%，收入 150 万 → 净 30 万；弱需求 30%，收入 80 万 → 净 −40 万。
> EMV_A = 0.7×30 + 0.3×(−40) = 21 − 12 = **9 万**。
> 方案 B（投入 160 万）：强需求 70%，收入 180 万 → 净 20 万；弱需求 30%，收入 130 万 → 净 −30 万。
> EMV_B = 0.7×20 + 0.3×(−30) = 14 − 9 = **5 万**。
> 9 > 5 → 选 **方案 A**；该分析属于**风险定量分析**（因为用了数值概率与损益）→ 选 D。

> **讲义 P139 决策树例题（已核对原图）**：建新厂投资 1.2 亿：强需求 60%、收益 2 亿→净 8000 万；弱需求 40%、收益 0.9 亿→净 −3000 万；EMV=0.6×8000+0.4×(−3000)=4800−1200=**3600 万**。改造旧厂投资 0.5 亿：60% 强需求 1.2 亿→净 7000 万；40% 弱需求 0.6 亿→净 1000 万；EMV=0.6×7000+0.4×1000=4200+400=**4600 万**。**4600 > 3600 → 选改造旧厂**。
> **注意**：这里"净收益"已经减掉了投资，**不要重复减**。

> **常见题型**：给 3–4 家分包商（报价、成功率、失败赔偿），项目成功获利 100 万。
> 某分包商 EMV = 成功率×(100 − 报价) + 失败率×(赔偿 − 报价)，取最大者。

### 2. 成本加激励费用合同 CPIF（P70，案例 6–8 分题）

**先记住三个量**：目标成本（TC）、目标费用（TF，即卖方的目标利润）、分摊比例（如 70:30，买方:卖方）。

**算法（按"成本节约/超支如何分配"）**：
```
实际成本 < 目标成本（节约）：
    买方支付 = 目标成本 + 目标费用 − 买方应享受的节约
              = TC + TF − 买方比例 × (TC − AC)
    卖方利润 = TF + 卖方比例 × (TC − AC)
    卖方实得 = AC + 卖方利润

实际成本 > 目标成本（超支）：
    买方支付 = 目标成本 + 目标费用 + 买方应负担的超支
              = TC + TF + 买方比例 × (AC − TC)
    卖方利润 = TF − 卖方比例 × (AC − TC)
    卖方实得 = AC + 卖方利润
```

> **例题（P70 第 1 题）**：TC=100 万、TF=10 万、分摊 70:30（买方 70%、卖方 30%）。
> **情况 A（实际成本 90 万，节约 10 万）**：卖方利润 = 10 + 30%×10 = **13 万**；买方支付 = 90 + 13 = **103 万**（也 = 100+10−0.7×10）。
> **情况 B（实际成本 110 万，超支 10 万）**：卖方利润 = 10 − 30%×10 = **7 万**；买方支付 = 110 + 7 = **117 万**（也 = 100+10+0.7×10）。

> **易错**：①"分摊比例 70:30"要确认哪一方是 70——按题干"买方:卖方"顺序；②**买方支付 ≠ 实际成本**，要加卖方利润；③若合同有**最高限价（ceiling price）**，买方支付不得超过限价。

### 3. 配置管理版本号（P69，选择题必考）

### 4. 资源受限排程（P71，选做但案例可能考）

题干特征：若干活动都需要 R1、R2、R3 三种**互斥资源**，资源总量有限，活动之间**无依赖**，求**最优安排与完工时间**。

## 七、高频陷阱 20 条

1. **EV 用的是计划单价**，不是实际单价。
2. **CPI/SPI 的分母**：CPI 除 AC，SPI 除 PV（别反）。
3. **CV/SV 的符号**：正数都好；**负的 SV 表示进度落后**，不是"超前"。
4. **典型用除、非典型用减**：看到"继续这样下去"就除。
5. **EAC=BAC/CPI 只在典型时成立**，非典型要用 AC+BAC−EV。
6. **BAC 不含管理储备**；**项目总预算 = BAC + 管理储备**。
7. **应急储备=已知-未知、在基准内**；**管理储备=未知-未知、不在基准内、需审批**。
8. **总时差=下减上（LS−ES 或 LF−EF）**；**自由时差=后减前（min 紧后 ES − 本 EF）**。
9. **关键活动总时差与自由时差都为 0**，但总时差为 0 的活动**不一定**在关键路径上（要看是否连通到终点）。
10. **多条关键路径**时，压缩工期必须**同时压缩每条关键路径**上的活动。
11. 压缩**非关键活动**不能缩短总工期。
12. **资源平衡会延期、改变关键路径；资源平滑不延期、不改变**。
13. **三点估算默认 β 分布**（4 倍中值），只有题目说"三角分布"才用 1/3。
14. **标准差 =(P−O)/6**，别除以 2 或 3。
15. **合并活动的方差相加**，标准差要**开方后再相加**（不是把 σ 直接加）。
16. **EMV 看清"收入/利润"**，避免重复扣成本。
17. **决策树属定量风险分析**（不是定性）。
18. **CPIF 买方支付 = 实际成本 + 卖方利润**，不是"目标成本+目标费用"。
19. **版本号 0 开头是草稿**；**修改状态第三位递增**（V2.13 是修改态）。
20. **计算题不写公式**，答案错就全丢分；写公式至少得分步骤。

## 十、附录：运筹学四类（讲义未涉及，选学）

> 讲义《03 计算专题》没有讲运筹学，但软考计算题里偶尔出现"线性规划求最大利润""最短路径""指派问题"这类小题。本节按考试常见问法给出**够用**的解法，不必深究证明；讲义正文没讲的部分都标在这里，不会与前面的口径冲突。

### 1. 线性规划（求最大利润/最小成本）

建模四步：

1. **设决策变量**（如生产 A 产品 x 件、B 产品 y 件）；
2. **写目标函数**：max Z = 利润系数 × x + ……（求成本则 min）；
3. **列约束条件**：资源/工时/需求上限，另加非负约束 x、y ≥ 0；
4. **求最优解**。

两个变量的解法（图解法，考试最常见）：

- 把每条约束画成直线，取满足不等号方向的公共区域（**可行域**）；
- **最优解一定落在可行域的顶点（角点）上**；
- 把各顶点坐标代入目标函数，取最大/最小者。

三个及以上变量用单纯形法，考试极少要求手算，多为判断选项。

### 2. 决策论（风险型与不确定型）

| 类型 | 已知条件 | 方法 |
|---|---|---|
| 确定型 | 每个方案结果唯一 | 直接比较 |
| 风险型 | 各自然状态**概率已知** | **期望值 EMV / 决策树**（见本册第五节） |
| 不确定型 | **概率未知** | 五准则（见下表） |

不确定型五准则（同一组收益数据，按题干指定准则作答）：

| 准则 | 做法 |
|---|---|
| 乐观（maximax） | 每个方案先取自身最大收益，再取其中最大 |
| 悲观（maximin） | 每个方案先取自身最小收益，再取其中最大 |
| 折中（Hurwicz） | 折中系数 α：α × 最大 + (1−α) × 最小，取大者 |
| 后悔值（minimax regret） | 每列先算后悔值＝该列最大收益 − 本格收益，每方案取最大后悔值，再取其中最小 |
| 等可能（Laplace） | 各状态概率视为相同，取平均收益最大者 |

### 3. 图论与网络

- **最短路径**：Dijkstra 标号法——从起点出发，每次在未定标的点中选距离最小者"定标"，用它的距离去松弛相邻点，直到终点定标。答题要把每轮标号写出来。
- **最小生成树**：Kruskal（边权从小到大选，**成环就弃**）或 Prim（从一点出发，每次选连到已选集合的最小边）；答案＝所选各边权之和。
- **网络最大流**：从源点到汇点找**增广路径**（还有剩余容量的路径），沿路径加压、更新剩余容量，直到找不到增广路径；**最大流＝最小割**。
- **别混**：进度题的关键路径是**最长路径**；网络题的最短路径才是最短。同一个图，两者答案必然不同。

### 4. 指派问题（匈牙利法）

目标：n 个人做 n 件事，一人一事，使总成本（或总时间）最小。四步：

1. **行减**：每行减去该行最小值；
2. **列减**：每列减去该列最小值；
3. **试指派**：用最少的横线/竖线覆盖所有 0；若**线数 = n**，0 所在位置即最优指派；若线数 < n，转第 4 步；
4. **调整**：未被线覆盖的元素减去其中最小值，**线与线交叉处的元素加上**该最小值，其余不变，回到第 3 步。

> 记忆：**"行减列减、划线试派、线少就调、交叉加回"**。

### 5. 本节用法

运筹题的特点：**步骤分多、结果唯一**。写出建模/标号/减法过程比只写一个答案更容易得分；万一模型不会，至少把"决策变量、目标函数、约束条件"或"图、权值、路径"写出来。

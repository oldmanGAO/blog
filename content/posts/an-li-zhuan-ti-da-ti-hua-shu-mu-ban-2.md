# 案例专题 · 答题话术模板（找错 / 计算 / 措施 / 列举 / 判断）

> 依据：《04：26.10案例专题》P2–P3（答题技巧与万金油）+ 各考点"Part1 答题小技巧"（P7 整合、P14 范围、P22 质量、P31 资源、P38 沟通与干系人、P46 采购、P55 配置、P61 变更、P67 风险）+ 参考答案的写法。

---

## 一、三条铁律（比背知识点更重要）
1. **分点写，一点一句**：按点给分；写成一段话等于自己把点埋掉。
2. **多写不扣分**：标准答案 3 条，你写 5 条，只要多出的不犯明显错误，不扣分 → 想到就写。
3. **绝不空题**：案例"答到点就有分"，不会也要往理论靠（先写过程名、再写"没有……"）。

补充两条（原书 P2）：
- **审题逐词逐句读**：案例材料里**基本每句对应 1–2 个考点**，看到"认为/觉得/大致/初步/匆忙"就是坑。
- **计算题写公式和步骤**：最后数字错了，步骤分还在。

## 二、万能四视角（拿到题先在这四个抽屉里找答案）
| 视角 | 问自己 | 常用句式 |
|---|---|---|
| **① 过程** | 49 个过程里，哪个**该做没做**、哪个**做了没做到位** | "没有制定××计划""××过程缺失""未开展××" |
| **② 关键词眼** | 材料里有没有下面 5 类信号词 | 见下表 |
| **③ 人员** | 经验、态度、安排、是否一人包办、沟通 | "经验不足""意识淡薄""身兼数职""一人包办""沟通不畅" |
| **④ 制度** | 评审/确认/验收、制度、工具、规则与绩效 | "未评审""制度不健全""未按流程""无考核机制" |

### 关键词眼 → 对应问题（P3 原表）
| 材料里的信号 | 直接对应的缺陷 |
|---|---|
| 客户验收不通过、争执、不满意、**多头汇报** | 沟通管理不到位 |
| **新**项目、**新**技术、**新**员工、**第一次** | 有风险、无经验、缺培训 |
| 修改、变更 | **没有走变更控制流程** |
| **之后才**发现了问题、延期 | 监控不到位、没有做好控制 |
| 认为、觉得、初步、匆忙、简单、大致 | 缺乏分析、内容不具体不详细 |

## 三、五大题型骨架

### A. 找错类（最高频，"请指出……存在的问题"）
**四步**：① 在材料里划出**矛盾句**（说了结果：延期/返工/验收失败）→ ② 往前找**原因句** → ③ 归到"过程/人员/制度/工具"四维 → ④ 每条一句，用"**没有/未/缺少/……不到位**"开头。

**每条答案的写法**：`缺陷（缺什么） + 依据（哪条管理要求）`，一句话一条，不加长句。
> 示范：`未制定范围管理计划，导致范围管理工作无依据。`
> 示范：`需求未经过评审和客户确认，导致后续设计与编码反复。`

**保底 5 条**（实在不会时按顺序硬套）：没有××计划 → 没有按流程执行 → 缺少评审/确认 → 沟通不到位 → 监控不到位未纠偏。

### B. 计算类（挣值 / 工期 / 关键路径 / EMV）
**五步**：`列公式 → 代入数据 → 算出结果 → 判断（>1/<1、>0/<0） → 写结论句`。

模板：
```
CV = EV − AC = ___ − ___ = ___ ，>0（<0），成本节约（超支）；
SV = EV − PV = ___ ，进度超前（滞后）；
CPI = EV/AC = ___，SPI = EV/PV = ___；
因题干"……"为典型（非典型）偏差，EAC = ___；
结论：项目当前成本___、进度___，按此趋势完工估算为___。
```
> 只写数字不写判断，最多给一半分。

### C. 措施类（"如果你是该项目经理，如何应对"）
**五段式**（P4 参考答案就是这个结构）：
1. **立即止损**：暂停/隔离问题模块，防止影响扩大；确认现状与影响范围。
2. **沟通对齐**：与客户/干系人沟通，明确需求与验收标准；与供应商/分包商沟通技术方案。
3. **技术方案**：组织专家评估，提出替代方案或补救措施，形成书面方案。
4. **合同与责任**：按合同约定追责、索赔或签补充协议；必要时终止并更换方案。
5. **长效机制**：纳入风险登记册、建立预警与监控机制、走变更流程、补充培训与流程文件。

### D. 列举/描述类（"请简述××的内容/步骤/作用"）
- 直接背点，**按顺序编号**（过程顺序、流程顺序），不要改写概念。
- 高频必背：项目建议书 4 项（必要性、市场预测、产品方案或服务预测、建设必需条件）；变更管理 8 步（提出、初审、论证、审查、通知实施、监控、效果评估、收尾）；配置管理 6 项（编制配置管理计划、配置标识、配置控制、配置状态报告、配置审计、配置管理回顾与改进）。
- 记不全时**补一句兜底**："并形成相应文档记录、经审批后执行。"

### E. 判断正误类（打 √ / ×）
三个检查顺序：**绝对词 → 主体 → 时序**。
| 检查点 | 常见错误 |
|---|---|
| **绝对词** | "必须""只能""全部""不需要""一定""任何情况下" → 多为 × |
| **主体** | 项目评估**必须第三方**（不能建设方自己做）；变更是否接受**不由项目经理决定**；配置管理计划**不由 CCB 制定** |
| **时序** | 先建议书后可研；先章程后计划；变更先申请后实施 |

## 四、分领域"找错"高频清单（按考点背，考场直接对号）

> 归类标签（过程/工具/人员/制度）为便于记忆的整理，原书按五维分栏排列。

### 1. 整合管理（P7）
- 【过程】没有制定项目整体管理计划；执行不到位；没有做好收尾与经验教训总结；监控不到位，没有认真核实可交付成果。
- 【过程】整体管理计划**不是各分计划的简单合并**，需要相互协调。
- 【人员】计划缺少分计划；项目经理经验不足；**计划应与团队共同制定**而非一人包办。
- 【制度】计划缺少评审和审批环节；项目已变更但**基线未变更**；没有制定整体变更流程；变更未走流程。
- 【其他】没做监控跟踪及时纠偏；**项目变更后合同未相应变更**；配置管理没做好、版本控制缺失。

### 2. 范围管理（P14）
- 【过程】无范围管理计划；无需求管理计划；未充分收集需求（渠道方式单一）；范围定义不清晰、内容不充分；未创建 WBS 分解到工作包；范围确认不到位；未控制范围 → **范围蔓延/镀金**。
- 【工具】范围说明书内容不充分，**缺少制约因素或假设条件**；未做偏差分析。
- 【人员】计划只由项目经理制定；未有效沟通；经验不足。
- 【制度】需求未评审、未获干系人理解和确认；无变更流程；需求/范围变更未走变更控制；**范围变更未对合同做相应变更**。

### 3. 质量管理（P22）
- 【过程】无质量管理计划或内容不充分；质量保证不到位；质量控制不合理、效果不佳。
- 【工具】未选用合适的质量控制工具；测试方法不当或不充分。
- 【人员】经验不足；**质量意识淡薄**；质量职责分配不合理；**没有独立于项目组的 QA 或 QA 未全程参与**；身兼多职顾此失彼；未提供质量培训；沟通方式单一；质量变更未走流程。
- 【制度】无质量保证体系；**缺乏质量标准和规范**；需求评审无客户参与；重大里程碑无阶段评审；质量控制缺少必要环节（评审、测试）。

### 4. 资源管理（P31）
- 【过程】无资源管理计划；无人员储备计划；团队组建不合理；团队建设没做好；未控制资源。
- 【工具】职责分配有问题导致推诿；未开展团队建设活动；冲突管理不到位；绩效管理缺失、无激励。
- 【人员】计划应团队共同制定；项目经理经验不足；团队缺乏沟通。
- 【制度】团队目标与岗位不明确；无成文的工作流程和方法；**无明确考核评价标准、赏罚不透明**；无协同与组织纪律。

### 5. 沟通 / 干系人管理（P38）
- 【沟通-过程】无沟通管理计划；沟通不到位；控制沟通没做好。
- 【沟通-工具】未分析干系人沟通需求；沟通渠道选择不当；无沟通记录；无沟通模板。
- 【沟通-人员】计划只由项目经理制定；未按实际有效沟通；经验不足；沟通问题未及时解决。
- 【沟通-制度】沟通需求未获干系人理解确认；沟通方法选择不合适。
- 【干系人-过程】未识别或识别不全；无干系人管理计划；未管理干系人参与；控制参与不到位。
- 【干系人-工具/制度】未做**权力-利益分析**；未把全部干系人纳入登记册；未向不同干系人提交其需要的信息；未针对不同干系人选不同方法与频率。

### 6. 采购与合同管理（P46）
- 【过程】无采购管理计划；实施采购没做好；控制采购未实时监控卖方绩效；结束采购未归档、未总结。
- 【工具】未编写采购工作说明书（SOW）；未做**自制或外购分析**；无供应商选择标准，选择过于随意（**只看报价最低**是经典坑）。
- 【人员】项目经理不重视采购管理；沟通存在问题。
- 【制度】采购流程不规范；**未做好货物验收**；**合同未规定索赔和违约责任**。
- 【其他】未综合考虑进度与货物交付时间；库存规划不合理；未记录采购文件与往来凭证。

### 7. 配置管理（P55）
- 【过程】无配置管理计划；配置管理过程无记录；**无配置权限机制**，配置混乱。
- 【工具】未做配置工具使用与培训；**未建立基线**，需求、设计无法对应。
- 【人员】未设专职配置管理员（CMO）；**配置管理计划不应由 CCB 制定**；**变更发布应交由 CMO**；身兼多职；经验不足。
- 【制度】无配置管理流程；**版本控制混乱**；变更管理不到位；变更缺验证环节。

### 8. 变更管理（P61）
- 【过程】未提交**书面**变更申请；未对变更影响做**完整分析评估**；未组建 CCB 或未审查；未实施变更；未监控变更实施；未形成变更记录；**未修改项目管理计划**。
- 【工具】变更影响未通知干系人。
- 【人员】未遵循变更控制流程；未认真审核；**CCB 组成成员不合理**。
- 【制度】变更结果未获客户确认；未做变更后评审；**是否接受变更不应由项目经理决定**。
- 【其他】版本与配置管理没做好；**变更后合同未相应变更**。

### 9. 风险管理（P67）
- 【过程】无风险管理计划或内容不全；未**全面识别**风险；缺定性分析（无优先级排序、概率影响分析）；缺定量分析（无量化）；无应对计划或措施无效；风险监控不到位、未跟踪已识别风险。
- 【人员】风险意识淡薄；**风险管理不应只由项目经理参与**，需全员与干系人共同参与；经验不足；沟通不畅产生不必要风险。
- 【工具/制度】无风险登记册；缺监控工具；未做风险再评估、审计与偏差趋势分析；未做技术绩效测量；**未充分评估进度风险及关联影响**。

### 10. 收尾管理（P79）
- 未按流程验收（范围确认/验收标准）；未移交成果与文档；**未总结 experience 教训并归档**；未释放资源；合同未收尾；未做客户满意度调查（可作兜底点）。

### 11. 综合类（P86）
- 多领域叠加题：先按"**立项/计划/执行/监控/收尾**"时间轴把材料分段，每段挂 1–2 个领域缺陷，再套四视角。

## 五、句式库（可直接抄进答卷）
- 没有制定《××管理计划》，或计划内容不充分、未经过评审与审批。
- ××过程执行不到位，未按项目管理计划开展。
- 未按变更控制流程执行：未提交书面申请、未做影响分析、未经 CCB 审批即实施。
- 需求/范围/设计未经过评审和客户确认，导致后续返工。
- 未建立配置基线，需求、设计、代码版本无法对应。
- 项目经理经验不足，缺乏××意识；身兼多职，顾此失彼。
- 计划由项目经理一人制定，未组织团队共同参与。
- 未识别全部干系人，未进行权力-利益分析，未纳入干系人登记册。
- 沟通渠道单一，未针对不同干系人选择沟通方式与频率。
- 合同未约定验收标准、索赔与违约责任，导致争议无依据。
- 监控不到位，未及时发现偏差并采取纠正措施。
- 未开展风险识别与应对规划，未建立风险登记册与预警机制。
- 项目结束后未做经验教训总结与文档归档。

## 六、考场动作清单（90 秒定框架）
1. 读题时用笔划**数字、角色、时间、结果词**（延期/返工/投诉/超支）。
2. 每题先写**答题框架词**（如"计划-执行-监控-变更-沟通"），再往里填句子。
3. 分值决定条数：**6 分≈4–6 条，8 分≈5–8 条**，宁多勿少。
4. 计算题先写公式再代数，最后补一句判断。
5. 留 5 分钟检查：有没有漏答小问、有没有把"不正确的是"看成"正确的是"。

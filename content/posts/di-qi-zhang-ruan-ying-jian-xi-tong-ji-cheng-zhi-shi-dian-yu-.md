## 一、系统集成基础（P87）

### 1. 集成目标的"四句话"（必背，第 1、5 题）

> **硬件系统集成是以信息的集成为目标，功能的集成为结构，平台的集成为基础，人员的集成为保证。**

| 要素 | 定位 |
|---|---|
| **信息集成** | **目标** |
| **功能集成** | **结构** |
| **平台集成** | **基础** |
| **人员集成** | **保证** |

### 2. 系统集成项目的 6 个特点（第 1、5 题）

1. 集成交付**队伍庞大**，且往往**连续性不是很强**；
2. 设计人员**高度专业化**，且需要**多元化的知识体系**；
3. 涉及**众多承包商或服务组织**，且普遍**分散在多个地区**；
4. 通常需要**研制或开发一定量的软硬件系统**，尤其是**信创产品和信创系统的适配与系统优化**；
5. 通常采用**大量新技术、前沿技术，乃至颠覆性技术**；
6. 集成成果使用越来越友好，**集成实施和运维往往变得更加复杂**。

## 二、基础设施集成（P87–P89）

### 1. 弱电工程（P87，第 9、22 题）

> **弱电一般指交流 220V、50Hz 以下的用电**，是电力应用按照电力输送功率的强弱进行划分的一种方式。

**六大弱电系统的拓扑与线缆（必背对照表）**：

| 系统 | 拓扑结构 | 线缆/介质 | 备注 |
|---|---|---|---|
| **电话通信系统** | **星形** | **三类（或以上）非屏蔽双绞线** | 传输信号频率在**音频范围内** |
| **计算机局域网系统** | **星形** | **五类或以上非屏蔽双绞线** | 传输**数字信号**，速率可达 **100Mb 以上** |
| **音乐/广播系统** | **多路总线** | **铜芯绝缘导线** | — |
| **有线电视信号分配系统** | **树形** | — | 布线采用树形结构 |
| **视频监控系统** | 视频信号**星形**；控制信号**总线** | 视频：**视频同轴电缆或光纤**；控制：**铜芯绝缘缆线** | — |
| **消防报警系统** | 信号传输**多路总线**；重要消防设备（消防泵、喷淋泵、正压风机、排烟风机）联动控制信号有时**星形** | **铜芯绝缘缆线**（有的产品要求双绞线） | **消防广播**通常多路总线、铜芯绝缘导线，**可与音乐/广播系统合用**；**火警对讲电话**通常**星形和总线两种结构**、**屏蔽线** |

> 其他常见弱电系统：**楼宇自控系统、智能化系统、电视会议系统、屏幕显示系统、扩声系统、巡更系统、楼宇对讲系统、三表（水、电、气表）自动抄表系统**等。
> **陷阱**：题干问"弱电系统不包括"时，常用"网络交换机/路由器""服务器"等**设备类**做干扰——它们属于网络集成的设备，不是弱电工程子系统。

### 2. 网络集成（P87–P88，第 24 题）

**网络集成的体系框架通常包括五个子系统：**

| 子系统 | 关键内容 |
|---|---|
| **传输子系统** | **传输是网络的核心**，是网络信息的"公路"和"血管"；传输介质分**无线**（无线电波、微波、红外线）与**有线**（双绞线、同轴电缆、光纤）两大类 |
| **交换子系统** | 见下表四种交换技术 |
| **安全子系统** | ①**防火墙**（分组过滤技术、代理服务器、应用网关）；②**数据加密**（对称如 DES、非对称如 RSA）；③**访问控制**（口令、密码、访问权限） |
| **网管子系统** | 关键任务是**保证网络良好地运行** |
| **服务器子系统** | **网络服务是网络应用最核心的问题** |

**交换技术分类（必背）**：

| 类别 | 技术 | 要点 |
|---|---|---|
| **局域网** | **共享式局域网交换技术** | 共享高速传输介质：以太网（快速以太网、千兆以太网）、令牌环、FDDI |
| | **交换式局域网交换技术** | 以**数据链路层的帧**或更小的数据单元（**信元**）为交换单位，由**硬件交换电路**构成交换设备 |
| **城域网** | **城域网交换技术** | 城市范围内建立的计算机通信网；采用**有源交换元件**的局域网技术，**传输时延较小**，传输媒介主要是**光缆**；典型应用为**宽带城域网**（IP 和 ATM 技术为基础、光纤为媒介、集数据/语音/视频于一体） |
| **广域网** | **电路交换** | 通过中间节点建立**专用通信线路**实现两设备数据交换（**电话网**即电路交换）；优点：**恒定传输速率、时延小**；缺点：**线路利用率较低** |
| | **报文交换** | 无专用线路，以**报文**为单位，经节点多次"**存储转发**"；优点：**线路利用率较高**；缺点：**传输时延较大** |
| | **分组交换** | 把数据划分成**固定长度的分组**（远小于报文）再"存储转发"，实现**更高的线路利用率、更短的传输时延、更低的通信费用** |
| | **混合交换** | 同时使用**电路交换和分组交换**，典型应用是 **ATM** |

> **考点**：第 19 题"在一个城市范围内所建立的计算机通信网……采用有源交换元件"→ **城域网**；第 20 题"电话网采用（电路交换）"；第 15 题比较四种广域网交换技术的优缺点。

### 3. 数据中心集成（P88–P89）

- 通常包括：**数据中心基础设施、通信机房、计算中心、数据处理中心、分布式计算、电信设备、网络和安全设备**等集成环境。
- **数据中心是组织信息环境最重要的部位之一，是信息化的神经中枢**（第 21 题）；设计、集成实施和建设应满足业务需求和安全管理要求的**安全性**，同时保持**充足的带宽和系统可靠性**。

### 4. 服务器集成（P88，第 10、23 题）

选择网络服务器时要考虑的 **7 个因素**：①**CPU 的速度和数量**；②**内存容量和性能**；③**总线结构和类型**；④**磁盘容量和性能**；⑤**容错性能**；⑥**网络接口性能**；⑦**服务器软件**等。

### 5. 存储集成（P88）

存储设备集成时要考虑的 **6 个因素**：①**磁盘阵列空间和类型**；②**配置硬盘的数量**；③**RAID 控制器结构**；④**支持 RAID0、RAID1、RAID5 或更多类型**；⑤**IOPS 读写性能和数据传输能力**；⑥**满足高可靠性，配置冗余热插拔的电源、风扇**等。

> **陷阱**：问"不属于存储集成考虑因素"时，常把"CPU 速度""服务器软件"塞进来——那是**服务器集成**的因素。

### 6. 网络设备集成与安全设备集成（P88–P89）

- **网络设备集成**：通常基于软硬件集成项目中的**网络规划与设计**，进行设备上架和连接，并完成**网络测试**。
- **安全设备集成**：数据中心的设计、集成实施和建设应具备满足业务需求和安全管理要求的**安全性**，同时还要保持**充足的带宽和系统可靠性**。

## 三、软件集成（P89–P91）

### 1. 操作系统（P89）

**（1）按运行环境分类（4 类）**：**桌面操作系统、服务器操作系统、手机操作系统、嵌入式操作系统**。

**（2）按功能分类（5 类，必背）**

| 类型 | 说明 |
|---|---|
| **批处理操作系统** | 主要功能是**批量执行**一系列事先编写好的作业；用户提交作业，系统按顺序执行并输出结果 |
| **实时操作系统** | 应用于**对时间敏感**的系统（航空航天、工业自动化），分**硬实时**与**软实时** |
| **分时操作系统** | 为**多用户和多任务**设计，可同时为多个用户服务，每个用户任务在时间上**交替执行**，给用户同时独占计算机的感觉 |
| **网络操作系统** | 基本功能：**数据共享（最核心的功能）**、设备共享、文件管理、名字服务、网络安全、网络管理、系统容错、网络互联、应用软件 |
| **分布式操作系统** | 多台计算机**协同工作**，把计算和存储任务分布到多台计算机上，提高**性能和可靠性**；在**资源管理、通信控制和操作系统结构**等方面与其他 OS 有较大区别 |

> **考点**：第 6 题"网络操作系统最核心的功能"→ **数据共享**。

**（3）操作系统虚拟化（第 14 题可能涉及容器）**

> **操作系统虚拟化是容器的核心技术**；允许多个应用在**共享同一主机操作系统内核**的环境下**隔离运行**，主机 OS 为应用提供一个个隔离的运行环境，即**容器实例**。
> 技术架构分 **3 层：容器实例层、容器管理层、内核资源层**。

- **加强操作系统安全加固工作也是整个信息系统安全的基础。**

### 2. 数据库（P89）

- **数据库管理系统（DBMS）是数据库系统的核心组成部分**，主要完成对数据库的操作与管理功能：数据库对象创建、数据查询/添加/修改/删除、**用户管理、权限管理**；**DBMS 安全直接关系到整个数据库系统的安全**。
- **分布式数据库**是数据库技术与分布式技术的结合；**并不注重系统的集中控制，而是注重每个数据库节点的自治性**。

### 3. 中间件（P89–P90，第 7、8、14、25 题）

> **中间件是独立的系统级软件，连接操作系统层和应用程序层**，将不同操作系统提供的**应用接口标准化、协议统一化，屏蔽具体操作的细节**。

**三个功能**：**通信支持（最基本的功能）、应用支持、公共服务**。

**六种中间件（必背）**：

| 类型 | 要点 |
|---|---|
| **事务式中间件（事务处理管理程序）** | 当前**应用最广泛**的中间件之一，主要功能是提供**联机事务处理**所需的通信、并发访问控制、事务控制、资源管理、安全管理、负载平衡、故障恢复等；**可靠性高、扩展性极强**，主要用于**金融、电信、电子商务、电子政务**等拥有大量客户的领域 |
| **过程式中间件（远程过程调用中间件）** | 逻辑上分为**客户机和服务器**两部分；通信可用**同步通信**或**线程式异步调用**；**异构支持能力好、简单易用**；因采用访问连接，在**易剪裁性和容错性**上有局限 |
| **面向消息中间件（消息中间件）** | 以**消息**为载体通信，利用高效可靠的消息机制实现不同应用间大量数据交换；通信模型两类：**消息队列、消息传递**；**非直接连接**，支持多种通信规程，达到多系统间**数据共享和同步** |
| **面向对象中间件（分布对象中间件）** | 分布式计算技术与面向对象技术发展的结合；**分布对象模型**是面向对象模型在分布异构环境下的自然拓展 |
| **交易中间件** | 专门针对**联机交易处理系统**设计的软件；可**大大减少编程工作量** |
| **Web 应用服务器** | Web 服务器与应用服务器相结合的产物；可以说应用服务器是**软件的基础设施**；直接支持三层或多层应用系统开发；**J2EE 架构是应用服务器方面的主流标准** |

> **考点**：第 8 题"提供联机事务处理所需要的通信、并发访问控制、事务控制、资源管理……"→ **事务式中间件**；第 14 题"不属于中间件"→ 常拿"操作系统、数据库管理系统、浏览器"做干扰。
> **易混**：**事务式中间件** vs **交易中间件**——前者是通用事务处理管理（金融电信等），后者专指**联机交易处理系统**的软件。

### 4. 办公软件（P90）

| 类型 | 特长 |
|---|---|
| **流式软件** | 处理**流式文档**，特长在于**所见即所得地编辑**文档 |
| **版式软件** | 处理**版式文档**，特长在于**原封不动地显示、打印、分享**原文件内容，**不做任何改动与编辑** |

- 与流式文件相比，**版式文档不会"跑版"**，在任何设备上显示和打印效果**高度精确一致**。
- **金山的 WPS Office 是典型的流式软件**，保存的文档是流式文件。

### 5. 应用软件集成（P90–P91，第 16 题）

**（1）CORBA 的五项功能**：**对象请求代理（ORB）、对象服务、公共功能、域接口、应用接口**。

**（2）COM 的五个特征**：

| 特征 | 要点 |
|---|---|
| **面向对象** | 在面向对象基础上发展，继承对象所有优点并进一步扩充 |
| **客户机/服务器** | 以 **C/S 模型**为基础，具有非常好的**灵活性** |
| **语言无关性** | COM 规范的定义**不依赖于特定语言** |
| **进程透明性** | 提供 **3 种**构件对象服务程序：**进程内服务程序、本地服务程序、远程服务程序** |
| **可重用性** | 用**包容和聚合**两种机制实现对象重用；用户程序只通过**接口**使用对象服务，不必关心内部实现 |

**（3）DCOM 与 COM+**

- **DCOM** 是 COM 的扩展，继承 COM 优点，并针对分布环境提供**位置透明性、网络安全性、跨平台调用**等新特性。
- **COM+** 是 COM 的新发展/更高层次应用，底层结构仍以 COM 为基础，**几乎包容 COM 所有内容**；主要特性：**真正的异步通信、事件服务、可伸缩性、继承并发展了 MTS 的特性、可管理和可配置性、易于开发**。

**（4）.NET 开发框架（第 13 题）**

| 组件 | 要点 |
|---|---|
| **通用语言运行环境（CLR）** | 处于**底层**，是该框架的**基础**；为多种语言提供**统一的运行环境、统一的编程模型**，简化发布升级、语言交互、内存与资源自动管理 |
| **基础类库（BCL）** | 统一的、面向对象的、层次化的、可扩展的**编程接口** |
| **ADO.NET** | 用于**访问数据库**，提供连接数据库、运行命令、返回记录集的类库；对 **XML** 提供强大支持 |
| **ASP.NET** | .NET 中的**网络编程结构**，可方便高效地构建、运行和发布网络应用，**还支持 Web 服务** |

**（5）J2EE（第 12、18 题）**

> J2EE 为搭建具有**可伸缩性、灵活性、易维护性**的组织系统提供了良好机制。

**J2EE 的四层体系结构**：**客户端层 → 服务器端组件层 → EJB 层 → 信息系统层**。

## 四、业务应用集成（P91–P92，第 2、3、4、17 题）

### 1. 三项技术要求

1. 具有**应用间的互操作性**；
2. 具有**分布式环境中应用的可移植性**；
3. 具有**系统中应用分布的透明性**。

> **陷阱**：第 4 题"不属于应用集成的技术要求"——常把"高可用性""可扩展性""安全性"塞进来，而讲义只写了**互操作、可移植、分布透明**三项。

### 2. 五项优势

**共享信息、提高敏捷性和效率、简化软件使用、降低 IT 投资和成本、优化业务流程**。

### 3. 三种连接应用组件的技术（必背对应关系）

| 组件 | 定义 | 典型题干 |
|---|---|---|
| **应用编程接口（API）** | 定义不同软件**交互方式的程序和规则**，可支持应用之间相互通信；利用特定数据结构帮助开发人员**快速访问其他应用功能** | 第 17 题"利用特定的数据结构，帮助开发人员快速访问其他应用的功能"→ **API** |
| **事件驱动型操作** | 当**触发器（即事件）**启动一个程序或一组操作时，系统就执行事件驱动型操作 | 第 2 题"订单提交后，进行计费并向客户开具发票"→ **事件驱动型操作** |
| **数据映射** | 将数据**从一个系统映射到另一个系统**，定义数据的交换方式，简化后续数据导出、分组或分析 | 第 3 题"在一个应用中填写联系信息表，信息被映射到相邻应用的相应字段"→ **数据映射** |

## 六、陷阱清单（15 条，逐条自测）

1. 集成目标四句话：**信息（目标）、功能（结构）、平台（基础）、人员（保证）**。
2. 弱电＝**交流 220V、50Hz 以下**。
3. 电话用**三类以上**双绞线，局域网用**五类以上**双绞线。
4. **有线电视分配系统是树形**，其他多为星形或总线。
5. 视频监控：**视频信号星形、控制信号总线**。
6. 消防广播**可与音乐/广播系统合用**；火警对讲电话用**屏蔽线**。
7. 传输是网络的**核心**；网络服务是网络应用**最核心的问题**。
8. **电话网＝电路交换**；**ATM＝混合交换**。
9. 电路交换"时延小但利用率低"；报文交换"利用率高但时延大"。
10. **数据中心是信息化的神经中枢**。
11. 网络操作系统最核心功能是**数据共享**。
12. 操作系统虚拟化是**容器**的核心技术，架构三层。
13. 中间件最基本的功能是**通信支持**；最广泛的是**事务式中间件**。
14. 版式文档**不会跑版**；WPS 是**流式**软件。
15. 业务应用集成三组件：**API、事件驱动型操作、数据映射**（"触发器启动"→事件驱动）。
